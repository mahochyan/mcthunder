Notes

- The icon set is monochrome, viewBox 24, stroke 1.75 and tinted at runtime with `modulate`; no icon is
  recoloured on disk, so one file serves every state.
- The Rajdhani faces carry Latin text and numerals only. Chinese text keeps the pre-existing Noto Sans CJK SC
  face, so no CJK glyph has to come from a Latin font.
- Three Lucide names were unavailable at the source (filter, history, circle-help) and were NOT substituted;
  the UI uses the names that exist.
- Fonts and icons are loaded by the engine itself (FontFile / Texture2D from SVG import), so this pass adds no
  build dependency and changes no build configuration.
