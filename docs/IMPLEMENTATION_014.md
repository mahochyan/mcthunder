# 014 实现方案
从013工程通过候选继续work/014-ai-combat。当前总策略low-poly，用户007—036连续授权有效。
- AIPerception内部接收真实实体用于距离/视野/实际装甲与WORLD遮挡查询；只向控制器交付可见的外部接触点、可见时速度估计与冻结last_seen。隐藏时不更新坐标，不提供模块/乘员/库存等敌方内部状态。
- 低频感知/决策和每物理步VehicleCommand分开。AITankController组合AIPathDriver，维护patrol/observe/engage/search/repair/retreat；last_seen搜索只去保存的位置或其最近图路点。
- 简单1.2s、普通0.7s、困难0.35s反应；角误差和决策周期独立配置，用带种子随机源。武器、装甲、装填、耐久不随难度变化。
- AimSolver只用可見外表点、可观察速度、己方真实弹速/重力求近似提前量和俯仰；偏差必须走有限转速炮塔，不能snap。反应未结束/炮塔未到位/无弹/炮闩坏/缺岗位不得请求开火。
- 开火前用实际炮口方向再次查WORLD/车辆最近接触，阻止墙体/友车/目标已隐藏后的旧瞄点射击；最终发射仍经Gunner与ProjectileManager自然冷却/库存/穿甲逻辑，AI不能直接写伤害。
- 只读自己的毁伤决定维修/灭火/替补或撤退，恢复请求仍走VehicleCommand与VehicleRecovery。死亡/重置/解绑取消观察记忆、目标与待开火意图，保留Actor代次门。
- 中文AI交战实验室从车库可达，玩家可在掩体边探出吸引射击并退回，状态显示为训练辅助；测试区分传感器输入与正常玩家图形操作。
