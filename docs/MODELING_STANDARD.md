# 外形建模标准

用户2026-09-08补充要求：体素模型不代表省略外观，外表尽可能接近原型。后续车型与本单都遵守此标准。

1. 先核对具体亚型身份，再对照前、侧、后、顶视图构建长度/宽度/高度、装甲斜率、炮塔与炮管比例。不能只做一个绿色车体盒和炮塔盒。
2. 保留决定车型辨识度的装甲轮廓、炮盾、悬挂型式、负重轮数量与位置、主动轮/诱导轮、履带路径、舱盖、观察镜、格栅、排气、牵引点与主要工具。圆曲面用足够细的分面/阶梯表现，体素尺度不能吞掉整个零件。
3. 主要装甲外皮直接来自命中布局顶点，车体/炮塔/炮管沿真实运动节点装配。装饰小件不伪称额外有效装甲。预览与驾驶使用同一构造来源。
4. 车库、前侧后近景、正常驾驶与转炮截图都要实机查看。检查轮廓和比例后才登记；自动通过不代替真人外观认可。
5. 几何与性能证据分开标注。当前 M4A3(75)W VVSS 是原创外形重建与训练设计参数的工程样车，尺寸估算、未认证历史性能；不冒充《战争雷霆》已存在的同名可玩亚型。

## 本次参考与实现

主要来源：美国陆军1944年《TM 9-759 Tank, Medium, M4A3》，Fig.3 顶视图（扫描PDF第11页），此前核对的外观与VVSS图见 `docs/ASSETS.md`。原始扫描保存在开发机资料目录 `E:/AIprogram/research-sources/TM9-759_TANK_MEDIUM_M4A3_1944.pdf`。只以公开手册为参考，不复制商业游戏模型。

`M4EngineeringProfile` 共用外形装甲面与射击几何；`M4VoxelDetails` 和 `M4TrackMotion` 将4,176个细节方块按实际部件/材质合为19组实例绘制。履带板沿封闭路径滚动，主炮外观随真实后坐状态回退。新模型接入中文车库、全部核心训练课目和地形训练。旧专项实验室保留原本明确标注的工程夹具，以维护既有物理反例与回归基线。
