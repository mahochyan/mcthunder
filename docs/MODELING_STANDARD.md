# 外形建模标准

2026-09-09 用户最新选择优先：正式车型约 1000 三角面；机械表面细节用概念图派生贴图，影响轮廓的部件才花费几何。025 当前四车为 M4 1016、M24 908、M26 1018、M36 970 三角面，完整模型上限 1100（含两侧履带，不含瞬时烟火）。轮辐、螺栓、格栅、接缝、舱盖细节、履带链节由 UV 贴图表现；轮组、连接悬挂、炮管、炮塔、机枪、天线及外部行李保留几何。下文的 16 边轮子、逐块履带是历史实现记录，不再作为正式四车要求。

用户2026-09-08最新策略：游戏定位low-poly低多边形；同时保留此前“外表尽可能接近原型”的要求。执行ART_DIRECTION_LOW_POLY，后续车型与当前迁移都遵守此标准。

1. 先核对具体亚型身份，再对照前、侧、后、顶视图构建长度/宽度/高度、装甲斜率、炮塔与炮管比例。不能只做一个绿色车体盒和炮塔盒。
2. 保留决定车型辨识度的装甲轮廓、炮盾、悬挂型式、负重轮数量与位置、主动轮/诱导轮、履带路径、舱盖、观察镜、格栅、排气、牵引点与主要工具。圆曲面用合适边数和清楚法线表现，几何不受体素网格限制。
3. 主要装甲外皮直接来自命中布局顶点，车体/炮塔/炮管沿真实运动节点装配。装饰小件不伪称额外有效装甲。预览与驾驶使用同一构造来源。
4. 车库、前侧后近景、正常驾驶与转炮截图都要实机查看。检查轮廓和比例后才登记；自动通过不代替真人外观认可。
5. 几何与性能证据分开标注。当前 M4A3(75)W VVSS 是原创外形重建与训练设计参数的工程样车，尺寸估算、未认证历史性能；不冒充《战争雷霆》已存在的同名可玩亚型。
