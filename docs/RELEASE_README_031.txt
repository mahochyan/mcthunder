PixelArmor — Windows x64 离线坦克战工程候选

解压整个 ZIP 到可访问的文件夹，双击 PixelArmor.exe。
保留同目录的 PixelArmor.pck。不需要安装 Godot 或 Blender。

推荐先在车库完成十章初训，再尝试三项挑战和两张地图的 4v4。
W/S 前后，A/D 转向，鼠标瞄准，右键炮镜，左键射击，Esc 暂停。
维修、灭火、换弹等按当前 HUD 提示。车库设置可改绑并调整音量和辅助选项。
显示模式预览 10 秒不确认就回退；全屏使用桌面尺寸。
正式比赛使用编成/配弹和有限弹药，战绩与研究点由实际结算保存。

当前有 M4A3(75)W 1944 VVSS、M24 1951、M26 1945、M36 1945 四个配置。
可玩内容：山村与工业地图、4v4 玩家与 AI、三项挑战、教学、车库配弹/研究/装甲查看。
没有联网对战、云存档、可破坏的无限地形或完整战争雷霆规模内容。
模型与音效为项目制作；历史来源、未知值和游戏化估算在车库资料界面分别标注。

配置与成绩在 Windows 用户目录，详见“数据与恢复说明.md”。
本包是工程验证候选。首次真人体验、平衡、长时间性能和最终发行签收仍需继续。
未签名且未公开发布，不要求关闭 Windows 安全保护。
精确源码/引擎/文件校验见 BUILD_MANIFEST.json。许可见随包说明。
