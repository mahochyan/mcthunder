# 009 实现方案
基线008登记2d413a4，work/009-damage-recovery。用户连续开发授权有效；沿用固定Godot。

- AmmoInventory每车独立，唯一总量为racks+chamber+in_transfer；发射只从膛内扣，装填搬移不造弹；保留fired/lost与初始预算守恒。旧rounds_remaining变为兼容读数，显式设置仅重新配置训练/测试库存。
- RecoveryRules集中驻车0.2m/s、灭火4秒/2次、维修12秒/目标50%、换位8秒、火灾1秒tick及0.05模块损伤。布局显式列出火传播模块与暴露乘员；暴露20秒失能为新增可解释游戏规则。
- VehicleRuntimeState保存正交火源、动作、维修进度、消耗品与终结记录；VehicleRecovery只在真实VehicleActor物理消费中推进，暂停冻结。有效发动机直击后<=25%点火；空弹架不殉爆，有弹架直击至0%才终结。本单不产生邻车爆炸伤害。
- 火源保存round/shooter/life/shot/projectile，环境空来源不冒领；统一destroy_once并在提交后发一次通知，死亡清动作与待发请求。显示和残骸只读取事件。
- T/F/C/G通过VehicleCommand和CommandMailbox提交维修/灭火/换位/取消。灭火开始扣一次，取消不退；维修移动车体或起火中断且保留本生命期进度，重置/死亡清空；换位按炮手再驾驶员，用尚可用非关键岗位成员补位，不复制人员。
- 单独Recovery Range保留008原有对照环境；1—5按明确新局配置训练断履带/发动机起火/炮手失能/有弹架/空弹架，伤害必须由实际玩家射击产生。Tab接管同一受损实体操作；面板展示进度/拒绝原因/耗材与死亡来源。
- 已毁车辆保留碰撞和装甲遮挡；数量/寿命有界的WreckRegistry负责清理，清理无死亡计分。默认12具、120秒，当前玩家观察实体保护到换场或切走，保护不会让注册无界。
- 自动反例覆盖库存守恒、同中空/实架、维修中断/不复活不补弹、灭火消耗与重入、换位失能/死亡/重置取消、火源归属和重复终结；窗口走真实菜单/瞄准/自然装填和恢复输入。
