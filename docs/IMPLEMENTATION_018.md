# 018 丘陵村落实施方案

起点：work/018-map-village，6ea0655f268d38e35b4f24dbe91dbbeb0a0b5c14；Godot 4.7.2 普通版 Compatibility。工作区仅有前单未入库的原始失败/过程证据，保留原状。007—036连续开发沿用用户授权；真人战术与手感待验收。

先建确定性灰盒与地图数据，再验证真实碰撞/驾驶，再加原创低多边形房屋、坡地和道路。320×320米适配现有速度与200米武器射程；两方±116米出生，中央12米据点，左右两条主路绕开±87米的实体出生遮挡，西侧另设长绕行坡路。80—180米为目标交火带，实测记录优先于设计数字。补给预留只画位置，不写弹药。

- MapDefinition持有边界、图节点、道路、出生点、掩体和资源身份，validate拒绝越界、无效图及无替代路线。
- NavigationBakePipeline把图边与真实物理世界核对（路面、坡度、最大4.2×2.4×8.5米代理形状），不把图连通当作实车可达。
- SpawnSelector统一复用现有实体/残骸占位查询，并检验敌方出生射界；保留灰盒作为016/017固定夹具。
- WorldCollisionRules统一实物与装饰分类。房屋/石墙/实板围栏挡车挡弹挡视线；低草不挡弹且不能遮住车辆；首版不放遮蔽性灌木。
- VillageRange复用TeamRange；只抽出地图图/出生点/目标/小地图四个钩子。车库团队战进入村落，重开保留地图。

工程验证：八个实际出生点的真实AIPathDriver到点计时、另一主路/长侧路、最大车宽通过、真实掩体弹道、出生安全、正常八车AI持续运行、地图打包加载、相关回归及正常菜单键鼠有限帧截图。不得把自动驾驶/截图称为真人体验。019之前只验证本地PCK资源加载，不在018导出发行版。
