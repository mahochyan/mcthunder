# 008 实现方案
基线：007登记56df38cde9658489338275270d2a8d6469d8d7b2，工作分支work/008-module-damage。用户连续开发授权有效。

- ProjectileManager仍唯一推进；从实际volume_intervals中选取下一模块/乘员进入点，在下一装甲/世界接触前处理。进入每个目标的授权按entity+life分开，穿透背面后撤销；未穿/UNKNOWN/掠射不能取得权限，外部履带独立允许。
- DamageResolver纯计算实际接触的模块/岗位及穿深消耗；不伤空舱/擦边/其他车。每发每模块最多一次确定性直击，保留有界seen集合。
- VehicleRuntimeState拥有独立模块完整度、五岗位乘员与单占位分配、去重事件及出局状态。配置来自布局；无整车总血量。状态提交无外部回调，管理器记录/预算提交后再发damage事件。
- VehicleCapabilities单一纯派生；Tank、Turret、Gunner通过同一状态提供器检查。发动机/任一履带/驾驶员丧失禁主动驾驶并滑停，炮闩/炮手丧失禁火，炮塔驱动丧失禁回转，装填手失能装填半速；少于2人失去战斗能力且只发一次终结。
- CrewRoster不允许一人重复占位，不允许给已失能乘员分配岗位。乘员来自具体布局，测试车使用5人明确设计夹具；不机械套旧4人模板。
- DamageRange使用真实车辆与薄甲布局、可读模块/乘员状态，Tab接管受损车。UI/外观只读状态，射击仍走玩家命令链。
- 回归覆盖真实未穿/空舱/近擦/多模块预算/外履带/跨车权限/炮塔旋转/独立状态/发动机与炮闩功能/死亡幂等与正常输入。火灾/殉爆/维修留009，回放留010。
