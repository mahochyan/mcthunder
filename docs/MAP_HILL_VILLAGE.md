# 丘陵村落设计与接口

320×320米、中心(0,0,0)、据点半径12米。双方主出生行位于z=±116，x=−27/−9/9/27；备用行位于z=±130。6米高的可见石墙横在z=±87，延伸至x=±56；左右入口x=±72保持宽阔转向空间。当前武器射程200米，AI感知180米，设计使用140米主路交火线与约93.5米坡顶侧射线，不把250米宣称为有效射程。

左右两条主进攻路线依次经过(±72,±116)、(±72,±50)、(±42,±20)，再驶入本队分散的圈内位置。出生开阔地同时连到两个入口；每条最短路逐边封闭后仍有替代。西侧长路经过(−120,65)、(−120,0)、(−120,−65)，可越过最高6.8米的缓坡，从对方前侧返回中央。低墙和村舍把近据点观察线切开，坡顶有视野也会暴露，不能当作无风险狙击台。

道路参数12米为导航通行带设计宽度；实测使用最大4.2×2.4×8.5米车体代理与实际车辆驾驶碰撞。图边细分为不超过22米，保证倒车后仍在DriveNavigator的16米节点接入范围；这也会使现有AI在中间节点减速，AI到点时间与玩家连续驾驶时间分别记录。实际大车经过主路、坡顶上下坡，堵路案例使用另一辆真实VehicleActor，驾驶器经探障/倒车/重规划改道，不直接移动载具。

VillageRange继承团队战规则，只提供世界、导航图、出生点和小地图元数据；所有伤害/友军阻挡/保护/再出击/据点/票数/结束冻结沿用TeamRange。灰盒TeamRange仍保留给旧固定场景检查。AppFlow团队战入口进入村落，重开保留村落并重新生成match_id。补给位置仅预留在z=±143，022前没有弹药/维修赠送。

MapDefinition.validate检查有限值、边界、图引用、最大车体和备用路线；NavigationBakePipeline.build对真实地形垂直射线、坡度与车体形状做每3米采样；SpawnSelector.evaluate复用正式重生安全查询，出生射界另用192条世界射线检查。WorldCollisionRules统一标签，所有固体同时用于车辆、炮弹与AI视线；不建立仅给AI用的隐藏障碍或忽略规则。

原始网格与资产来源见ASSETS_018。道路为纯视觉贴片，不投射贴地阴影以免出现阴影闪纹；地面视觉与实体地形共用同一三角网格。屋顶凸包先填顶点后挂入已运行物理世界，避免空凸包初始化错误。AI前方探障射线沿真实支撑平面投射，修复可爬坡面被水平射线误报为墙的问题。

所有尺寸与时长为工程设计值。原始自动日志区分固定步实车夹具、完整自然八车运行、正常键鼠窗口与仅数据PCK导出；真实用户的正面/侧翼战术体验仍待验收。
