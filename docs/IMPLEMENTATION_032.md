# 032 平衡测量方案

031 的固定提交独立构建继续执行时，先准备不改变战斗参数的测量工具；031 未通过前不登记 032 交付。

`run_balance_matrix_checks.gd` 装配真实四车、真实两弹种、原始装甲网格和内构状态。四种射手分别攻击四种目标，在 100/500/1000 米、前后左右、两种高度和两种横向偏移生成 1536 发记录。以零重力的水平入射隔离距离穿深和碰撞几何，这是明确的数学/几何夹具，不冒充玩家远程瞄准成绩。每发重置目标的完整状态及 generation，交给生产 ProjectileManager / ArmorResolver / DamageResolver 结算，输出表面名称、接触角、剩余预算、乘员和模块结果。

`run_balance_match_checks.gd` 使用两图、两个种子、两种阵营配置共八局自然比赛。每边均为四种真实车型，各自的随机误差种子作为固定 AI 队列交换阵营，重生也继承同一分配公式。普通难度、初始票数、自然计时、装填、毁伤、占领和结算不改；测试不直接写死亡或比赛分数。保留完整种子、地图、阵营、结算、射击、通路失败及资源数据。这是小样本筛查，不能证明公平，更不能代替真人四车两图试玩。

本次测量阶段没有修改历史装甲、装填、炮塔转速或挑战星级阈值。先检查实际异常；必要调整优先通过出生路线、任务或公开游戏规则实现，并一次只改一类参数。AP/APHE 的取舍由成对实测例子说明，不要求每个距离和方位强行各赢一半。
