# MCTHUNDER / low-poly 美术与产品定位

生效：2026-09-08。用户最新要求：“定位游戏为low-poly，低多边形而不是单纯体素”。本文件覆盖早期计划中的体素、方块化与统一体素尺寸要求；之前交付记录保留当时真实状态。

## 产品定位
以原创低多边形3D画面呈现有辨识度的装甲车辆和战场，陆战内容继续尽可能还原战争雷霆式观察、瞄准、弹道、分区装甲、内部毁伤、乘员、维修、再出击与目标争夺。视觉策略调整不削减既定007—036玩法路线。

## 造型优先级
1. 具体亚型身份、尺寸比例和正侧后轮廓优先。车体斜面、炮塔体积、炮盾、炮管长径、悬挂类型和轮组数量必须可辨认。
2. 用干净的多边形面表现结构。轮子、观察塔、炮管允许低边数圆柱；铸造炮塔、炮盾和石头允许分面曲面；平板装甲保留真实斜面。表面不强制栅格或阶梯化。
3. 舱盖、观察镜、灯罩、格栅、牵引点、排气与主要工具按辨识价值保留。低多边形控制的是不必要的几何密度，不能省略整类关键零件。
4. 统一有限色板、粗糙度与柔和环境光，靠形体和适度明暗分出部件。小纹理可补充标记与磨损，不能代替车型轮廓。
5. 场景采用相同视觉尺度：建筑清楚结构面，岩石和地形自然分面，树木保持低多边形体积。不是把所有场景件都做成同一种方盒。

## 工程边界
- 外观、驾驶碰撞、装甲面、模块盒使用同一尺寸与运动节点。改视觉不能悄悄改装甲厚度、模块耐久或穿深。
- 默认可重复的程序网格或GLB流程；需要编辑器时采用明确版本与导出规范。VOX仅是可选参考来源；选型以轮廓、质量与许可为准。
- 按三角形、材质/绘制批次、动画成本和整场实测性能管理预算。初步目标为主坦克约6千至1.8万三角形，最终以025/029多车场景测试调整，不能据此声称目标硬件已达标。
- 既有体素资源可参考或重制，资源许可仍必须遵守。历史数据、视觉估算与游戏设计参数保持独立标注。
