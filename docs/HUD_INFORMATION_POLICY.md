# 正式战斗信息权限（017）
BattleHUD只接收HUDPresenter与BattleIntel的视图数据。车辆状态来源为本地当前生命的真实VehicleRuntimeState、Gunner和AmmoInventory；没有另一套HUD装填/维修/火灾计时器。

己方车况可显示模块是否完好、受损或损毁，岗位是否可用，驾驶/火炮限制，动作进度与上次拒绝原因。模块状态不合成为整车血条。底部驾驶原因、火炮原因、起火、动作及反馈各占独立字段。

小地图的地形与据点为公开地图。友军实时位置为队伍信息。敌人只来自当前观察车的AIPerception外表视线扫描：按炮塔方向150度视场、180米范围、真实世界与车体遮挡，最多每0.3游戏秒一次。当前观察车是活着的本地玩家，或阵亡时所观察的活友军；切换观察生命会清空旧标记。阵亡观察不会接管友车或读取其敌方内部信息。

失去视线的敌人显示空心菱形问号，位置冻结在最后目击处，最多保留6游戏秒；不读取其隐藏后的实时位置或航向。实心菱形只表示当前扫描可见。敌方3D名称标签也受相同可见身份限制。友军用三角形、敌方用菱形，并有文字图例；高对比模式保留形状差异。

Tab战况只显示编成ID、友敌队伍与公开出局次数，不提供敌方模块、乘员或隐藏位置。正式X光与实验室检视入口不开放。回放只在本局结束后、且玩家未关闭回放偏好时允许；其画面来自已冻结实弹记录，不对活世界再次判定。

圆点与圆圈投影来自Gunner.actual_hit_point，是炮管当前直线指向；不是穿深提示或重力弹道落点预测。观察方向的小十字与真实炮管圆标分开。

Tab打开/关闭战况；阵亡Q/E切换观察友军。战况和编成不暂停比赛，暂停菜单才冻结世界。InputFocusRouter在界面、阵亡、结果和回放时禁用本地战斗意图，返回驾驶先清请求并要求火键释放，避免点击按钮同时发炮。

HUD字体100/115/125%、高对比、炮口闪光、稳定镜头与结算回放偏好仅在本次应用运行内保留，存盘属于029。镜头震动默认关闭；可选震动只使用相机光学偏移，不改瞄准/发射所用变换。设置不会改变装填、装甲、伤害、票数或AI性能。
