# PixelArmor 首版候选说明

PixelArmor 是 Windows 离线 low-poly 坦克游戏。玩家在两张原创地图中参加 4 对 4 占点战，用有限弹速、弹道下坠、分区装甲与乘员/模块毁伤进行交战。修复、灭火、弹药选择、有限出击和阵亡后的重生都会影响一局的结果。

首批四个具体配置为 M4A3(75)W 1944 VVSS、M24 1951、M26 1945 和 M36 1945。包含 AP/APHE 两类效果、车库配弹与装甲查看、轻量研发、三项挑战、十章初训、中文设置和本地成绩保存。训练与普通模式的解锁/奖励规则不同，具体以车库提示为准。

解压整个候选 ZIP，保持 EXE 与 PCK 同目录，双击 PixelArmor.exe。无需另装 Godot 或 Blender。W/S 前后，A/D 转向，鼠标瞄准，右键炮镜，左键开火，Esc 暂停；其它按键及改绑见设置和 HUD。先完成初训，再尝试侧翼猎手和两图普通对局。

数据保存在 `%APPDATA%/Godot/app_userdata/PixelArmor`，迁移和损坏恢复说明随包提供。反馈请记下 BUILD_MANIFEST 的 source_sha、地图、车型、弹种、操作顺序以及观察到的结果；截图和日志由用户自行决定是否分享，不自动上传。

这是一份简化坦克战候选。它没有联网、完整战争雷霆车型规模、真实履带链、车体冲量/弹簧阻尼悬挂或逐物体真实破坏。枪管视觉后坐与已有火光不能当作已完成车身物理后坐。历史数据来源、几何估算和游戏化近似分开，不宣称等同真实车辆或其它游戏的完整物理模型。

宣传截图必须来自明确候选的实际运行窗口，保留截图哈希和来源记录。ImageGen 概念图、99A 建模图不能作为此四车首版的实机画面。跨机器最低配置、陌生玩家易用性和用户接受尚待实际验证，不做无证据的性能承诺。
