# 018 环境资源登记

丘陵村落为原创确定性程序地图。原始可编辑文件为scripts/maps/village_definition.gd与village_world.gd；地图图、地形采样、三角网格、房屋山墙屋顶、木门窗、实体石墙/实板围栏、道路与0.28米草片均在工程源码中生成。种子18018仅控制小草散布，作战布局非随机。

未下载环境素材、纹理或模型，不含其他游戏导出资产，不购买资产。环境源文件随本工程可交付与版本管理；项目自身许可仍沿用仓库规定，不对第三方权利作额外声明。既有中文字体与OFL完整文本沿用ASSETS_011.md，无改动。

房屋视觉屋顶与凸包用同一组6个顶点，山墙不会成为无碰撞装饰；门窗只表现封闭表面，不能进入。实板围栏采用连续木板外观，按不可穿固体处理。无茂密灌木，没有仅AI能看穿的遮蔽物。草片低于履带/车体关键观测高度，无碰撞。道路贴片不挡弹，真正支撑面是与地形视觉共用三角数据的物理网格。
