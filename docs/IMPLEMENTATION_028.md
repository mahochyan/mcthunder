进度写入 ProfileStore 原有双槽，schema 3 新增 `tutorial={chapter,completed}`。只接受范围内整数与无重复章节数组；schema 1→2→3 显式迁移，保留 profile_id、revision、配弹、研究、战绩。保存失败显示未保存，可重试同一已验证章节；重复完成不再次提交。教学重置仅清教学，返回车库恢复此前选车与专项课目。

Guide 在场景准备后加载，保持生产 AppFlow 依赖解析顺序；没有修改全局车辆生命或挑战尝试编号以处理脚本退出问题。
