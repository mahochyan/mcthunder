# WT-006 落地判定与近地腾空

开发基线 `7a3f213`。继续落地响应接入检查时，发现 GroundProbe 将“射线测得地面距车体原点不足0.55m”与碰撞求解器的落地状态并列。0.55m原本用于区分履带可达支撑，不能证明正在下落的车体已经碰地。旧判断会在真实碰撞之前恢复加速、制动、转向与俯仰回稳。
