# WT-CD-001｜空弹架、搬运弹与动态毁伤占用

优先级：**P1** · 关口：**G1** · 发布状态：planned

前置：无；一次最小基线核对后开始

关联旧单：WT-010, WT-014, WT-015（仅关联，不覆盖旧职责）

## 依据与边界

待复现风险：上一轮调用链提示空架可能仍进入盒体命中和预算消耗；本次抽查快照及模块求解仍值得验证。不是已实测Bug。

来源：[R01] [R06] [R07] [W02]

## 玩家新增能做什么

少带弹真正减少可命中的弹药体积；空弹架不再凭空吸收弹丸或发生弹药损失。

## 先读的生产入口

`scripts/query/query_snapshot_builder.gd`  
`scripts/query/shot_query_service.gd`  
`scripts/damage/damage_resolver.gd`  
`scripts/damage/vehicle_recovery.gd`  
`scripts/vehicle_actor.gd`  
`scripts/gunner.gd`  

路径是审查线索；后继重命名时只做一次定向定位，不因路径未命中就宣称系统不存在。

## 必须设计

1. 分开ammo_contents、rack_structure与compartment_barrier。弹药耗尽不等于隔板或钢支架消失；每种实体有自己的命中/阻力策略。
2. 运行快照加入不可变的弹架占用和revision，覆盖在架、已预留、搬运中、膛内及已损失五种状态。装填使用现有库存服务，任何一发只占一个定义清楚的位置。
3. 首版以实际装填顺序激活子体积；没有逐发几何时采用明确的分区占用近似，不把库存比例简单乘到整个盒子的穿透阻力。
4. 同一物理步内前一发导致弹架清空后，后一发不得使用已过期占用；方案可选提交时复核并重查，或事件有序更新派生快照，必须保留相同时刻的位姿。
5. 缺占用状态明确incomplete/拒绝，不把未知默认为空；固定布局缓存不缓存动态库存结果。

## 实现顺序

1. 先在两车相同射线路径上做满/半/空架对照，记录实际命中对象、预算消费、库存前后，不先改代码。
2. 证实后只补查询快照、动态过滤和提交复核的最小缺口；若未复现，保留闭合证据，不制造diff。
3. 接入现有Inventory和HUD采样；只增加必要的显示字段，不在UI另算占用。
4. 对照无修改基线与新实现，重跑装填、弹药守恒、模型/布局和恢复相关套件。

## 必须交付

1. 满/半/空实弹对照JSON及事件路径
2. 动态占用契约与限定范围生产补丁
3. 六场景结果和受影响回归
4. 正常配弹后少带弹的演示

## 六项验收设计（当前均NOT_RUN）

### CD01-T01｜同一路径满架与空架

操作：从已确认炮口和姿态用同种工程弹分别射击。

预期：空架不产生ammo_contents损伤或弹药预算消耗；独立支架/隔板仍按自己的规则有效。

### CD01-T02｜半装与分区占用

操作：通过正常配弹和取弹使指定子区耗尽。

预期：命中活动子区和空子区结果不同；占用与库存账本对应。

### CD01-T03｜最后一发在搬运或已装膛

操作：推进自然装填并在每阶段取快照。

预期：无重复弹体；离架后不留满架幽灵，膛内弹仍可追踪。

### CD01-T04｜同一物理步两发先后到达

操作：首发毁坏/泄压清空架，第二发沿同路径到达。

预期：提交按时序复核占用；第二发不重复损失同一批弹药。

### CD01-T05｜切弹、补弹、重生及回放

操作：正常切弹/补给后重生，再只读回放旧事件。

预期：占用正确重建且旧回放不改新生命库存。

### CD01-T06｜缺少占用与旧缓存

操作：删除必需占用字段或带旧revision请求。

预期：明确不完整/重查，不能以空架PASS。

## 拒收条件

1. 仅让HUD隐藏弹架，后台仍结算满架
2. 为了空架测试删除隔板或改穿深
3. 重置时把消耗过的库存补回
4. 用格式校验代替实际接触

## 通用交付规则

遵守05_DELIVERY_AND_ACCEPTANCE.md。设计不代替实现，规则检查不代替实弹，源码不代替独立包，夹具不代替正常局，工程检查不代替真人。

# WT-CD-003｜有限截面弹丸与运动目标接触

优先级：**P1** · 关口：**G1/G2** · 发布状态：planned

前置：WT-CD-001, WT-CD-002

关联旧单：WT-010, WT-011（仅关联，不覆盖旧职责）

## 依据与边界

源码审查：主命中路径为线段；已有平移扫掠但不等于弹丸体积或旋转连续碰撞。

来源：[R02] [W01]

## 玩家新增能做什么

炮弹不再像无尺寸针穿过窄缝，同时接缝不会凭空叠出数倍装甲。

## 先读的生产入口

`scripts/projectiles/projectile_manager.gd`  
`scripts/projectiles/projectile_state.gd`  
`scripts/query/shot_query_service.gd`  
`scripts/query/query_geometry.gd`  
`scripts/query/translation_sweep.gd（按实际路径确认）`  

路径是审查线索；后继重命名时只做一次定向定位，不因路径未命中就宣称系统不存在。

## 必须设计

1. 定义ProjectileShapeProfile：bore_caliber_mm与effective_projectile_shape分开；APFSDS不用炮膛直径冒充弹芯。缺实测形状采用独立工程profile并标design。
2. 3A静态有限截面先落地，3B相对平移，3C旋转部件。采用有界多射线/扫掠凸体之一并写出采样和误差边界，不假定任一方式天然精确。
3. 同物理板在同一连续接触episode只计算一次；不同真实层仍分别作用。反弹后再次真正进入同板属于新episode，不用永久plate去重吞接触。
4. 装甲、模块、乘员、世界遮挡和后效统一采用接触时刻；预算上限到达返回明确incomplete，不当作无命中。
5. 保留v1线查询的显式旧规则入口作对照；新工程弹不能因缺shape偷偷回退旧线规则。

## 实现顺序

1. 先建立比弹体窄/相当/宽的人工缝隙与单板基准；用期望几何而非被测函数算测试答案。
2. 实现3A，并以两车实际炮盾和侧裙验证；交付G1时明确3B/3C待完成。
3. 在同一接口逐步接平移和旋转，重查后效快照时间；不一次重写查询缓存和网络。
4. 修正接触记录和回放字段；按变更影响重跑装甲、弹丸、世界遮挡。

## 必须交付

1. ProjectileShapeProfile及实际工程弹配置
2. 分阶段窄缝/接缝/运动目标用例
3. 接触TOI、板件ID和去重日志
4. 3A可玩检查点及3B/3C完成记录

## 六项验收设计（当前均NOT_RUN）

### CD03-T01｜静态窄缝

操作：用三个已声明截面的工程弹通过系列缝隙。

预期：无阻挡直穿只发生在相容几何；碰到边缘必须走材料结算而不是必然停弹。

### CD03-T02｜大缝与切向擦边

操作：分别通过宽缝和掠过单板边缘。

预期：宽缝不假挡，边缘产生稳定接触；终端结果另由规则决定。

### CD03-T03｜同板/真双层

操作：用相同几何的细分单板和独立双板射击。

预期：单板不因射线数变厚，真实双层保留双层作用。

### CD03-T04｜子步拆分与容量

操作：改变渲染fps/内部细分并触发查询预算边界。

预期：可比场景结果在声明容差内；预算耗尽明确失败。

### CD03-T05｜平移目标

操作：目标侧向通过高速弹路径并作解析对照。

预期：炮弹与目标使用一致接触时间，无跨tick固定偏置。

### CD03-T06｜旋转炮塔与车体运动

操作：转塔/俯仰同时射击边缘和内部靶。

预期：接触/内构同一时刻，旋转边界不伪装成已完成静态回退。

## 拒收条件

1. 把所有碰撞盒等比放大冒充体积弹
2. 多条射线重复扣同一块板
3. 靠减速或禁转炮塔掩盖漏判
4. 仅3A通过却把整单完成

# WT-CD-004｜弹道时间、速度与火控预测一致

优先级：**P1** · 关口：**G2** · 发布状态：planned

前置：WT-CD-003

关联旧单：WT-007, WT-010（仅关联，不覆盖旧职责）

## 依据与边界

源码审查：飞行主要重力、距离穿深曲线独立；穿透预算与残余速度未建立统一更新。

来源：[R02] [R03] [W03]

## 玩家新增能做什么

测距、提前量和穿后引信基于同一套时间与速度，不出现瞄具算一条、炮弹飞另一条。

## 先读的生产入口

`scripts/projectiles/ballistic_math.gd`  
`scripts/projectiles/projectile_state.gd`  
`scripts/projectiles/projectile_manager.gd`  
`scripts/projectiles/ballistic_intercept.gd`  
`scripts/gunner.gd`  
`scripts/vehicle_actor.gd`  

路径是审查线索；后继重命名时只做一次定向定位，不因路径未命中就宣称系统不存在。

## 必须设计

1. 建立BallisticsProfile版本：单位、初速、重力、可选经验阻力/速度衰减与寿命/距离上限；第一版选择一种可校准近似，不同时上多套空气模型。
2. 实际飞行、火控、AI预计命中共用一个求解服务；不复制一份HUD用抛物线。
3. 接触返回明确的residual_velocity规则。穿深预算不是焦耳，不能直接将毫米代入动能公式；映射属于项目设计并单独标定。
4. 长距离距离穿深、速度衰减和装甲扣耗不得重复惩罚；记录空气段和接触段分别消费。重力导致速度变化不等于凭空增能。
5. 初速继续包含已支持的车体速度；炮口角运动项只有实现/验证后才声明；每弹固定随机种子避免帧率影响散布。

## 实现顺序

1. 冻结0阻力解析基准与一套工程阻力曲线，先输出时间/落点/速度表。
2. 接入权威弹丸和预测器，再接穿透后速度/引信；旧历史配置显式使用v1，不静默改变其曲线。
3. 在200/500/1000/1500 m范围内按武器有效射程采样，明确超范围不作性能承诺。
4. 完成运动射手/目标和壁后引信专项，禁止直接调瞄准答案掩盖求解差异。

## 必须交付

1. 同源弹道服务和两类profile
2. 射程/飞行时间/速度/落点对照表
3. 穿透前后速度和引信时刻记录
4. 更新的预测/实际一致性回归

## 六项验收设计（当前均NOT_RUN）

### CD04-T01｜零阻力基准

操作：按固定初速/重力发射多个角度。

预期：数值结果与解析答案在事先设定容差内。

### CD04-T02｜经验阻力配置

操作：同弹逐距离记录速度和时间。

预期：符合冻结设计曲线，未实测历史数据不标validated_history。

预期：引信按残余轨迹起爆，不按穿透前恒速凭空推远。

操作：使用正常运动发射并进行同条件对照。

预期：继承速度与目标时间基准一致。
