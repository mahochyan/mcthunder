# WT-008 机构与稳定能力增量

本批在统一工程接入 `FireControlProfile` 和固定物理步 `TurretMechanismState`，不是 WT-008 整项签收。真实炮塔追瞄使用有界加速、制动、反向响应，机构输出仍受车型水平/俯仰限制。所有新增默认响应参数属于 `game_rule`。

稳定能力可配置为无、垂直、双轴；以真实 HullFrame 基底变化求补偿，不把视线稳定当作炮管已经到位。补偿服从机构最大速度、损伤、速度阈值及迟滞。进入观察、暂停、换控制者与重生清除旧机构速度和积累姿态，观察期间保持局部机械轴。相同基底严格返回零补偿；真实微小姿态变化仍计算。

现有正式车辆没有因通用模块名字而自动获得稳定器。只有明确配置的 `turret_horizontal_drive`、`turret_vertical_drive`、`stabilizer` 模块才参与独立能力降级；原有炮塔驱动/炮手失能规则保留。新增模块可沿既有自然维修流程恢复。

工程证据：`logs/WT-parallel/c193693-integrated-wip2/20260912-150459` 中34项纯机构检查通过；`logs/WT-parallel/c193693-integrated-wip4/20260912-151736` 中41项真实Actor专项通过，退出0，无脚本错误。专项使用明确TEST ONLY/game_rule三车，在实际地面/坡道上经PlayerController驶入、转向和开火；比较无/垂直/双轴能力，并在发射同物理步核对实际炮口、炮管和继承车速。真实穿透分别损坏水平、垂直机构和稳定器，HUD按实际模块种类显示原因，12秒自然维修恢复到原规则的半强度；暂停、重生与无旧发射重放也通过。

夹具路线平均俯仰偏差：无稳定0.004865rad，垂直稳定0.000368rad；转弯水平偏差：无稳定0.06972rad，双轴0.004587rad。数值只描述该声明的游戏规则和输入路线，不能代表具体历史车型。首次Actor专项漏初始化输入映射、第二次错把保留的累计发射计数当零，失败日志保留；修订以暂停前后弹数/累计发射/shot_id/projectile_id全量不变验证。

基础217项回归在同一wip4目录通过。有限飞行遮挡夹具改为炮弹结束后才拆墙；收敛检查仍要求≤0.5°连续保持1秒，但为新加减速与响应迟滞提供5秒总预算；快慢炮塔对比在1秒窗口观察，避免仅比较二者相同的初始加速阶段。没有靠取消机构加减速来满足旧瞬时转速假设。
