# WT-006 制动点头与回稳

开发基线 `44cd04f`，工作树 `codex/rc3-playability-fixes`。本轮按用户要求继续驾驶主线，性能优化与完整局性能采样保持暂缓。

## 实际行为

固定物理步内，`TankVehicle` 将本步纵向速度变化传给 `ChassisResponse`。受限目标俯仰通过临界阻尼响应推进；加速抬头、前进制动点头、倒车加速低头、倒车制动抬头，停车后回到地面姿态。每步先移除上次附加俯仰，再跟随地面并施加新响应，避免逐帧叠加。腾空时保留起跳姿态与响应状态，重置清零。

响应直接作用于真实车体变换，其移动碰撞、炮口与装甲查询共同使用该姿态。移动方向仍沿地面切线，不把点头角当成爬升方向。网络快照增加 hull_pitch/hull_roll，客户端插值并显示；缺少新字段的旧快照回退零角，非有限值拒收。当前欧拉角插值服务于受限坡地驾驶，不能代替翻覆情况下的完整姿态同步方案。

DriveProfile 保存设计参数：默认每 m/s² 加速度对应 0.18 度，最大 1.5 度，响应率 8/s；M4A3 为 0.22 度和 7/s，M24 为 0.16 度和 10/s。均为游戏调校，不是历史悬挂数据。

这只是纵向载荷转移的简化车体响应。尚无逐轮弹簧/阻尼、轮地载荷、垂向压缩、落地冲击、侧向动态侧倾、侧翻与拖救。碰撞停车仍不提供完整冲击力矩。WT-006 保持进行中。
