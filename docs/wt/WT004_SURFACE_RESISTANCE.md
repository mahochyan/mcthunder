# WT-004 路面滚动阻力

开发基线8632a19，遵照用户主线开发优先、性能优化暂缓的指示。新增DriveSurface附着到真实地面碰撞体，GroundProbe用原有5条实际地面射线取得接地点，按有效支点平均滚动阻力；未接地时为0，不增加隐形道路碰撞体。

村落terrain默认grass，工业区terrain默认concrete。道路区域复用绘制道路的road_visual边、端点和横向宽度（村落5.5m/工业7m，含斜边横向投影系数），仅作为地面材质区域，降低视觉细节不移除阻力。无标记的旧训练地面保留unclassified=0；soft_soil已可用于作者配置与测试，但本次未新增泥地地图区域。

GameConfig集中游戏设计阻力加速度：road=0.12、concrete=0.2、grass=0.55、soft_soil=1.0m/s²。不是实测历史滚阻系数。DrivePowertrain消费该数值，影响驱动加速度、滑行和刹车，保持正反方向、不从静止倒推车辆；腾空不施加阻力。单侧断带应急转向仍是上一批简化规则，尚未加入该路径的地面摩擦求解。

原始首批证据`logs/wt004-surface/8632a19-surface-wip/20260911-152146`：路面15、动力19、地形25、历史车型道路17项通过。两辆真实Actor从静止持续4秒同样油门，在road/soft_soil均匀碰撞地面夹具中，M4距离14.7037/8.7883m，M24距离23.2985/17.1084m。夹具明确指定整块地面材质，不是完整对局或真人试驾成绩。实际支点返回正确阻力，路边支点混合值处于两种阻力之间，空中接地缺失为0。
