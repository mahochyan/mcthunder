# WT-006 接地丢失与恢复

开发基线b440de4。原TankVehicle先按转向输入改变朝向，并无条件推进动力；grounded仅用于坡阻和地面姿态。现在每步先取真实GroundProbe，再允许有支撑时的履带牵引。失去有效支撑时，油门/反向制动/滑行不改纵向速度，方向键不提供车体偏航，重力与原碰撞求解继续运行；保留腾空姿态，不自动朝水平复位。重新接地后原动力/差速/断带规则继续生效。

这是现有CharacterBody3D驱动底座的接地门控，不是完整刚体抛体或悬挂模型：水平运动仍由纵向速度与平面朝向重建，未加入自由角动量/轮地逐点牵引/腾空时发动机空载转速。grounded仍沿用GroundProbe实际射线与近地支撑阈值，不能声称接触点或落地压缩已经精确求解。悬挂、制动点头、部分支撑、推挤/翻覆/拖救均待后续。

接地采样从转向之后移至之前，同一物理步使用当前支点决定牵引资格，再旋转车头；不额外增加一批地面射线。真实炮口/装甲仍随生产车体姿态，不新增仅视觉旋转冒充驾驶。
