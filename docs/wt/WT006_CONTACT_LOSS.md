# WT-006 接地丢失与恢复

开发基线b440de4。原TankVehicle先按转向输入改变朝向，并无条件推进动力；grounded仅用于坡阻和地面姿态。现在每步先取真实GroundProbe，再允许有支撑时的履带牵引。失去有效支撑时，油门/反向制动/滑行不改纵向速度，方向键不提供车体偏航，重力与原碰撞求解继续运行；保留腾空姿态，不自动朝水平复位。重新接地后原动力/差速/断带规则继续生效。

这是现有CharacterBody3D驱动底座的接地门控，不是完整刚体抛体或悬挂模型：水平运动仍由纵向速度与平面朝向重建，未加入自由角动量/轮地逐点牵引/腾空时发动机空载转速。grounded仍沿用GroundProbe实际射线与近地支撑阈值，不能声称接触点或落地压缩已经精确求解。悬挂、制动点头、部分支撑、推挤/翻覆/拖救均待后续。

接地采样从转向之后移至之前，同一物理步使用当前支点决定牵引资格，再旋转车头；不额外增加一批地面射线。真实炮口/装甲仍随生产车体姿态，不新增仅视觉旋转冒充驾驶。

新增真实Actor测试明确使用30m高、6m/s、12度俯仰的受控初态，并非正常输入开上跳台。分别保持正油门、反向油门、释放输入并持续转向30物理步，均保留6m/s和原姿态且真实下落；另从1.5m落地，重新接地后实际命令恢复加速与转向。其12项与地形25、差速15、断带21、路面15合计88项通过，证据`logs/wt006-contact/b440de4-contact-wip/20260911-152722`。

## 部分履带支撑（开发基线42edc36）

GroundProbe保留原五射线和地面姿态查询，另外用车体局部系高度与0.55m有效支撑距离区分四个履带端点是否实际可提供牵引。中心射线用于车底/姿态参考，不直接当履带接地点。左右各两个端点，每个贡献该侧0.5；普通动力/制动/滑行按左右平均比例限制，普通转向按较弱侧限制，单侧断带应急转向按完好侧的支撑比例限制。GameConfig统一支撑距离。地面射线看到沟底不等同履带受到支撑。

这是离散支点的游戏模型，未求解各支点法向载荷、单侧支撑产生的车体侧翻力矩或滑移。当前普通转向在一侧全悬空时停止，非宣称模拟了完好单侧对车体的全部力学作用。悬挂和制动点头仍待实现；车底托住且履带全悬空时牵引为0，拖救尚未实现。
