# WT-013 HEAT独立射流路径

开发基线01d5bdaf。WT-012/013/027/030仍进行中，42项要求未删减；性能HOLD_BY_USER、真人NOT_RUN、release_ready=false。本批提供明确游戏规则的HEAT基础，没有交付3BK18M/DM12真实参数、完整现代防护或苏德整车。

## 接入行为

参考弹药目录增加HEAT/heat_fs_tank/chemical准确对应。heat_fs_tank名称来自现有苏德摘要，但摘要的hitPower仍不是穿深。射流必须有独立chemical_profile与匹配的game_rule证据，缺失配置、曲线、材质规则或误贴AP/APHE规则均拒绝。现有候选文件、未知字段和正式车型名册未改写。

ShellDefinition与ProjectileManager要求弹体距离穿深曲线为同一化学预算，防止把动能距离衰减套入HEAT。Gunner冻结chemical_profile和wt012-chemical-v1材质响应。响应使用实际斜向厚度和明确化学材质系数，不用法线化、炮口口径碾压或动能跳弹；未知厚度/材质仍停止结算。

有限速度弹体第一次碰到装甲、外部模块或实体世界时结束飞行，保留真实接触位置与飞行时间。ChemicalJetSystem在该时刻的几何姿态上执行独立的有界射流：从已确认的第一接触开始，依次处理装甲、模块、乘员和世界遮挡。首面不会因从表面重查而跳过，之后只抑制同一表面的零距离重查。载体飞行距离不扣化学预算；起爆后的路径损失、装甲与内构阻力按同一射流账本依次扣除。每次最多16个接触，射程和路径损失是单独登记的游戏设计量。

射流既不继承APHE球形爆破，也不对偏轴模块施加范围伤害；不借用母弹的consumed_mm或破片数组。对局保护与真实damage_handler仍决定伤害是否可提交。账本和索引先保存再通知回调，回调重置后立即停止后续射流；中断过程不冒充完整记录。

本批为首次接触起爆及有限即时射线模型，不声称完整引信灵敏度、真实射流成形、爆压/外部爆破、复合装甲或ERA效果。路径损失也不是历史材料实验值。后续HEAT触发/后效和现代防护继续保留。

## 回放

chemical_effect独立保存弹体接触点、载体方向、接触帧、起爆时间、射流路径、有序装甲/伤害索引与剩余预算。回放分别显示弹体轨迹与起爆后的射流路径，不出现APHE爆点；拖动时间不会重复提交伤害。

校验载体方向/时间与触发帧、前向路径/射程、事件完整链接、路径损失与逐接触预算，以及材质响应版本。该门证明记录内部一致性，不是完整物理重演或密码学真实性保证。
