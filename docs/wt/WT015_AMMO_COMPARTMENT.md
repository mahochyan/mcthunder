直接受损使带弹架完整性归零时，隔板完好且没有涉及该架的取弹/补弹事务，才结算该架物理存弹损失。已入膛弹与其他弹架不变，泄压部件置为损坏；已经泄压的部件仍允许泄压。隔板损坏、正在取弹/补弹或无隔离配置的带弹架仍按既有规则殉爆。T-80B 没有凭空获得这一保护。弹丸继续走原有装甲与乘员/模块结算，保护不赋予乘员免伤。

受损弹架、隔板与泄压部件接入正常维修优先级。维修只恢复完整性，随后由 Gunner 的实际计时和库存事务从备用架补弹；不能恢复已损失弹药。HUD 和射击说明显示尾舱损失。回放增加可选 ammo_compartment 规则版本、冻结隔离部件状态、逐弹种损失和前后库存，检查数量守恒、无额外库存改动、事务关闭和版本；兼容 JSON 整数解码成浮点数。旧记录没有该字段时保持兼容。网络协议仍为 6、命令 3、姿态 1、内部快照 3，本轮不宣称新增完整网络模块同步。
