# WT-003 瞄准与武器范围对齐

基于f724c9d。检查发现生产历史车型的弹丸累计路程预算早已是2500米（VehicleContentPipeline），但CameraRig远裁剪400米，普通观察/精确装甲查询300米，炮镜粗查询150米，空查询则指向60米。这使具备较长弹丸预算的车型无法用相同范围观察、选中目标，远处空射方向还受近处会聚影响。

现在三种瞄准路径统一使用 `max(300, weapon.gun_range+20)`，20米是第三人称相机偏移余量；无接触时沿同一射线回退到查询终点。相机远裁剪为 `max(400, query_distance+100)`。历史车型实际得到2520米查询/2620米远裁剪，旧200米测试武器仍是300/400米。CameraRig绑定实际WeaponDefinition；重新配置武器会清除旧瞄准缓存。

GameConfig集中记录上述距离关系，以及既有历史弹丸预算2500米、AI感知180米和声音240米。AI与声音仍读取原数值，本批没有把AI改为远距离全知，也没有扩大声音传播。弹丸真实飞行仍受各武器累计路程、弹种存活时间、重力和遮挡约束，查询距离不是有效射程或命中保证。2500米是既有游戏预算，不是本批核验的历史有效射程。

## 验证

tests/run_engagement_distance_checks.gd建立明确的长距离夹具：实际历史M4武器、另一辆历史车辆的真实装甲、长地面与可移除遮挡墙。三种查询在500/1500/2400米都选中B车，空中回退一致，800米处世界墙遮住1500米靶车；另一次正常命令发射使用生产AimSolver、Gunner与ProjectileManager，真实炮弹命中1000米处装甲，产生两次接触。未修改弹速或关闭毁伤来通过测试。

专项15项通过。`logs/wt003-distance/f724c9d-distance-final/20260911-124543`另含恢复64和反馈40项通过，全部退出0且无SCRIPT ERROR/ERROR。初批基本靶场216、AI交战34、阶段8项通过，见 `logs/wt003-distance/f724c9d-distance-wip/20260911-124153`；初批之后仅增加configure_weapon清缓存。

真实1280×720窗口自由观察9项通过，包括鼠标观察/炮塔不转、炮镜优先级、松开恢复、菜单/重置和旧按键迁移。日志 `logs/wt003-free-look.stdout.log` / stderr，截图 `logs/wt003-free-look.png` 已查看，保存检查成功；测试可显式传截图路径，不覆盖之前自由观察证据。相关检查合计386项。长距离选择与远裁剪属性是自动检查，不把普通自由观察截图冒充2400米目视辨识或远距画质验收。

## 剩余范围
