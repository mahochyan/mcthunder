# WT-013 APHE延迟引信与车外破片

2026-09-12，基于dea5244dbd5c9100baf9d785d1d345902a0290d2，由主代理单独实现和验证。WT-013仍为in_progress；本增量不代表完整毁伤、现代两车或发布验收完成。

## 实际行为

ShellDefinition新增可选fuze_policy，经过历史/参考弹药目录、实际Gunner发射，复制到独立ProjectileState。空配置保持旧试验场的0.8米内部路径规则；正式历史车的M61/M82选项已明确配置延迟模式。正常选弹不改变膛内弹，实际装填后才使用下一弹种的引信。

只有向内成功穿过已知装甲、且本次LOS等效厚度达到阈值时触发计时。薄板、未穿透、未知装甲、跳弹和出射背面不触发；后续装甲不会重置已触发的时刻。计时按炮弹模拟年龄推进，切分真实弹道子段到截止时刻；出车、原目标消失都不撤销它。寿命/射程到期优先于同刻引信，取消/重置不能留下后续爆炸。

引信触发后，被装甲、模块或世界挡停的弹体归零速度，保留剩余计时；车体部件有有效身份和变换时保存局部停留点，随后按每步末部件姿态更新。世界停留点固定。网络当前弹丸基线使用零加速度表示挡停状态，原发射重力仍保存在回放中。完整连续载体运动与预测恢复尚未实现。

延迟模式破片使用现有有界射线、装甲预算、真实模块/乘员事务和比赛规则；不再强制截断在首次被击中车辆内。起爆在车外时，只有穿过装甲后才取得对应目标的内部命中资格，外挂模块可按实际几何受损，世界遮挡优先。仍最多12条破片、每条3米/8次接触、12毫米游戏预算；不新增冲击波、HE范围伤害或装药物理模型。旧内部路径模式保持原限制。

回放保存原发射配置、触发/截止时刻、起爆位置、车内外状态、停止原因和实际破片路径。校验配置与发射记录一致，拒绝篡改计时。原目标已移除时允许明确无当前目标几何的车外起爆，不伪造现场模型；原接触几何仍保留。回放显示不重复结算伤害。

## 数值来源

configs/shells/historical_loadouts.json中的三款APHE选项使用独立规则wt013-aphe-delay-design-v1：8毫米LOS触发阈值、0.003秒模拟延迟。它们是可调整的游戏初值，不是M61/M82的历史引信性能；provenance=game_rule、historical_value=null保留未知。没有由补弹时间、hitPower、口径或穿深推导引信。

参考车辆包若显式配置引信，必须同时提供独立structured证据条目且值完全一致；游戏设计不能登记为历史verified。车库来源说明展示延迟起爆的用途与未知边界。未配置引信的旧包保持兼容，T-80B/豹2A4候选没有因此获得整车准入。
