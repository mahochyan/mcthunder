## 两处导航缺陷与限定修复

1. **第 0 个路点没有可封闭的前序图边。** A/A2 相向停在道路 (-259.0378, 220.03) 与 (-252.3133, 220.03)，均指向 (-256.596, 220)。原逻辑每次等待后调用同一规划器，路径起点不变，始终没有恢复动作。现在仅在首个路点被真实车辆阻挡时使用既有的有限倒车/转向恢复；后续图边仍优先绕行。不改速度、恢复次数、碰撞或车辆支撑条件。
2. **行驶车辆驶离后，原阻塞仍永久封路。** 为带控制器的活车辆单独登记弱引用、实际阻塞位置与车型长度余量；只有原阻挡车辆离开该位置超过长度余量或实例已移除，才释放这条临时封路并重规划。墙体、停放车辆、残骸和已登记永久阻塞不按时间或距离自动过期；新的静态阻塞会撤销该边的动态分类。同目标重试继续保留永久阻塞记忆。
