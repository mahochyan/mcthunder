## 2. 车辆能力差异/反制说明（交付物第二条）

| 方面 | T-80B | 豹 2A4 | **反制（按事实，不按车名）** |
|---|---|---|---|
| 装填 | 转盘自动装填 28+10，**无装填手岗** | 人工装填 15+27 | **断电使自动装填停止，而人工装填仍工作**；自动装填的待发架更早耗尽 |
| 传感器 | 热像 **+ 夜视** | 仅热像 | **两个通道都遵守烟幕与掩体规则**，夜视优势不是穿墙优势 |
| 乘员 | 3 人，无装填手可伤 | 4 人，装填手受伤即停装填 | 人工装填对断电更耐受，但对乘员伤亡更脆弱 |

## 3. 事实与调校分离 + 平衡杠杆

| 类别 | 示例字段 | 说明 |

## 5. 现代对抗样片（六场景，实测全通过）

| 场景 | 结果 |
|---|---|
| 远距对射（1200 m，无遮挡） | 热像可用、测距可用、通道无衰减 ✓ |
| 远距对射（2000 m，烟幕） | **光学完全阻挡**、**热像衰减 0.6 不阻挡** ✓ |
| 侧翼 | **16v16 与 10v10 均同时存在进攻道与绕行道** → 两侧都有攻防选择 ✓ |
| 坡顶 | 山脊高于车道（有观察位；但"高"仅在通道能看见时才有用）✓ |
| 烟幕撤退 | 共享遮蔽对象生效；**装填不受烟幕影响且守恒** ✓ |
| 受损装填恢复 | 中断 → 修复 → 复装 → 击发，**账户全程守恒**（两种机构各测）✓ |

**范围声明（写入样片报告）**：`not_a_gunnery_duel = true` —— 两车无战斗定义，样片检验的是**机构与装备**，不含弹道/装甲/准入结论。

**配弹影响库存（不只是 UI）**：同车不同配弹 → **膛内弹种不同 + 弹架构成不同**，击发返回实际装填的弹种（实测）。
