
## 2. 决定性反证：**同路线孤立成功**

位置恰在孤立运行的**中途点附近** ✓

## 3. 结论（修正我上一轮的口径）
- `supply` 失败**不是**"路线几何不可达"（补给点平地、宽 12、孤立可达）；
- 而是**长序列电池内的不稳定/状态相关失败**（同一世界连续跑数十条路线、每条创建并释放车辆）；
- 这与先前地图套件"孤立成功、电池内失败"的**同族现象**一致；
- 因此上一轮"40 → 30 净改善 / supply 两分支相同"的对照**必须加上"套件自身存在轮间方差"这一保留**——已启动**同分支二次运行**以量化该方差（`cont-industrial-run2.log`）。

## 4. 下一步
1. 用二次运行与首轮、以及同预算基线三轮做**集合稳定性分析**：把"两轮均失败"的条目视为**稳定项**，把"仅某轮失败"的视为**噪声项**；
2. 稳定项才立为独立条目（如确属 supply 收口）；
3. 噪声项登记为**套件稳定性问题**（与地图套件同类），并提出测试侧加固（每路线独立世界 / 路线间收敛断言），**不改判定语义**。
