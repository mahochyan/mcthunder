## 2. 机构差异（实测）

| 项 | 表现 |
|---|---|
| 炮塔方位/炮管俯仰 | 固定步内由机构求解；渲染帧不写权威朝向（`run_turret_tick_checks` 的 `render_does_not_turn`） |
| 俯仰限位 | 不得把不可达目标谎报为已对准（`run_optics_checks`） |
| 战损 | `turret_drive` 损毁后**无法建立新瞄准**：实测新瞄准残余 **6.07°** vs 保持旧瞄准 **0.35°** |

## 3. 交战配置差异（重要口径登记，**本单未改动**）

| 载体 | 量程 | 来源 |
|---|---|---|
| 遗留训练车 `player_tank` | **200 m**（射线预算） | `GameConfig.GUN_RANGE`、`configs/player_tank_weapon.tres` |
| 已准入历史车（M4A3/M24/M26/M36） | **2500 m**（弹丸预算） | `GameConfig.HISTORICAL_PROJECTILE_RANGE_M`，由 `vehicle_content_pipeline.gd:233` 赋值 |
| 河谷歌河谷枢纽地图 | 世界 2400×2000 m；布局边界 10v10 ±740/±600、16v16 ±1040/±800 | `RiverJunctionDefinition` |

**入口差异**：`RiverJunctionRange` 独立进入时默认 `selected_vehicle_id = "player_tank"`（200 m）；经车库正常入口进入才会带入所选历史车（2500 m）。→ 在 200 m 配置下该图的远距交战不成立。这是**参数/入口决策**，改动属"改战斗参数"红线，故只登记不执行。

## 4. 按键与中文原因提示

| 操作 | 默认键 | 说明 |
|---|---|---|
| 炮镜 | 按住右键 | 进入瞄准镜，弹道解从镜内视角发起但**射击一律从真实炮口出膛** |
| 望远镜 | 按住 `L` | 车长观察；权威端保持炮塔/炮管局部轴并**禁火** |
| 测距 | `Y` | 保持观察方向与车身稳定 2 s；不自动改变装定 |
| 采用读数 | `H` | 用测得距离装定；过期读数不能再采用 |
| 装定增减 | `[` / `]` | 每次 100 m，降至 0 恢复直瞄 |
| 倍率循环 | 可重绑 | 只切换配置内的 FOV 档 |
| 自由观察 | 可重绑 | 不污染已保存的炮口意图 |
| 开火 | 左键 | 单发，自然装填 |

中文提示（`assets/localization/zh_CN.json`）：
`range_status_*` = 尚未测距／正在估测／估测距离／测距失败／测距已过期；
`range_reason_*` = 操作已中断／观察模式或乘员状态变化／请保持观察方向与车身稳定／目标无法判定／量程内没有目标 等；
开火受阻原因集（`hud_presenter.gd`）：`barrel_occluded`（炮口被遮挡）、`cooldown`（装填中）、`grace`（恢复宽限）、`no_ammo`／`chamber_empty`（无弹）、`turret_drive`／`gunner`（机构或乘员失能）、`vehicle_disabled`（整车失能）等。

## 5. 河谷射击路线与正常输入记录

| 项 | 内容 |
|---|---|
| 站位 | 生产部署停位选择器 → 索引 4 = 中央跨河通路 `(0, 90)`，朝向 −Z |
| 设计射距 | **近 250 m / 中 550 m / 远 850 m**（均在图内、在 10–2000 m 测距与 2500 m 弹丸预算内） |
| 瞄准 | 生产 aim point 驱动炮塔：残余 **0.53° / 0.39° / 0.35°** |
| 开火 | 三距离开火门均接受，各**恰好消耗一发**膛内弹，弹丸离膛并产生终止记录 |
| 弹着 | 三距离终止均为 `impact_world`：**直射线跨越河谷洼地与桥体结构**，未接触目标 |
| 真实输入开火 | `run_river_driving_checks`（34/34）用 `Input.action_press("fire")` 证明"正常玩家输入开火恰好消耗一发" |
| 炮口遮挡 | 在炮口处放置 1.6 m 世界方块后：开火被拒、`blocked_reason=barrel_occluded`、弹数不变 |
| 观察切换 | 连续切换 望远镜/自由/追逐/炮镜 各 12 帧：装填计时只前进、膛内库存不变 |
