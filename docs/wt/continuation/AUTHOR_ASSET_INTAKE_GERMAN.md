## 3. 本单交付：只读入库审计工具与报告

新增 `tests/export_german_intake_audit.gd`（**只读**）：
1. 枚举 `<root>\*\vehicle.glb`；
2. 逐车：**字节数 + SHA-256**（`FileAccess.get_sha256` 绝对路径）+ **三角面数**（GLTFDocument 解析后累加 `mesh.get_faces()/3`）+ 外形包络/单位候选 + **六角色解析**（复用 `ModelBindingProbe` 逻辑）；
3. 输出 `logs/WT-030D-r2/german_intake_audit.json`（机器可读）并打印汇总（含"≤15,000 三角面"与"角色 6/6 / 部分 / 缺失"的**逐车计数**）。

**该工具不改动任何源文件**；其对应用途是：把"能否登记/需要什么作者工作"从判断变成**逐车清单**，从而推进 WT-030D / WT-031B-D（车池量产与注册）。
