## 3. 关键设计决定

1. **零外推**：缺包冻结（不编造运动）——比"有上限外推"更保守且与生产一致；把"不支持"写成可断言事实（`extrapolation_supported()==false`）。
2. **延迟即生产常量**：`INTERPOLATION_DELAY_TICKS = NetworkPoseBuffer.DELAY_TICKS`，套件断言相等 → 防止模型与实现漂移。
3. **窗口有界**：重演与补偿都是 **6 tick**，绝不回溯整场世界。
4. **单一结算者**：`settlement_owner()=="server"`，从结构上排除"同一弹双结算"。
5. **纠正必留痕**：预测被拒 → `corrected=true` 且 `kills_credited` 恒为 0；未预测的拒绝如实记未纠正（不静默吞掉）。
6. **注入确定化**：同种子同条件同调度，故障逐条成纠正事件 → 失败可复现。

## 5. 自纠记录（我的断言语义错误，2 处）

1. 以为显示时刻会**瞬跳**到插值目标 → 实现是**渐进追帧**（clamp 到目标），已改为"渐进且不超目标、足够帧后精确落在目标"。
2. 以为重演窗口是**条数上限**（≤6 条）→ 实现是**tick 距离**窗口（6 tick 内可有 7 条输入），已按真实语义断言。
两处均**未放宽安全性断言**（不外推、不回卷、单调、纠正不记击杀始终为硬断言）。
