# WT-075-R1 登记：重车"坡上起步"能力冲突（驱动侧修复九次均不可行）

## 1. 观测事实（D 电池末段轨迹，M26 `uphill-production-driver`）
```
tick=9000  wp=17 dist_wp=1.64  pos=(-119.97,0.10,-44.98)          ← 已几乎走完
tick=9600  phase=reverse  reason=insufficient_actual_progress  attempts=3
tick=9660  phase=turn_recovery  steer=1.00 thr=0.00  pitch=10.72°  ← 恢复把它停在坡上
tick=9720  phase=following wp=0 dist_wp=9.48 thr=0.77 speed=0.000
tick=9750~9810  thr=0.77（consumed 一致、submit_ok=true）· speed=0.000 · 位置逐字不变
           stuck_s 0.33→0.83→1.33→1.83（**卡死检测工作正常**）
tick=9822  attempts=4 → phase=failed reason=recovery_limit
```
**关键对照**：同一坡段它此前能以 **2.5 m/s** 行驶（有动量）；`pitch≈10.4–10.9°`；**该坡道本就已铺装**（drag 0.12）→ 非地面分类问题。

## 2. 结论
**M26（四车动力最低：`forward_max=8.94` vs 11.62/15.20/11.62）在 ~10° 坡道上"从静止起步"时，到点曲线给出的 0.77 油门推力不足以克服重力分量；一旦恢复流程（`turn_recovery` 只转向不给油）把它停在坡上，就无法再起步 → 用尽恢复次数 → `failed`。**

这属**动力 × 坡度调校**问题（与已由用户选定 C 修复的"草地阻力"红线**同族但机制不同**）。
