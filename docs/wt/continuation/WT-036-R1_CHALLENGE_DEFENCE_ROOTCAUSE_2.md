## 2. 修正后的根因
场景：`zone=(-78,0,100)`、**`radius=18`**、**`hold=45(hard)`**、`limit=150(hard)`、
**敌人 B1=(-78,25)、B2=(-95,25)（距占区约 75 m）**、`enemy_rounds=12`。
导演：`success = held >= hold and kills.size() == enemies.size()`。

实测（`pwsh-17` 修复后重跑）：
```
held=45.0（已达上限，条件①满足 ✓）
kills={}  player_shots=0  ← 条件②完全未满足 ✗
enemies=[{ id:B1, position:(-77.96,0.0007,25.91), dead:false, shots:12 }]
```
⇒ **唯一缺口：脚本飞行员一枪未发**；其开火需 **通视(`clear`) + 对准** 同时成立，而在 75 m 外（占区以北）从未成立 ⇒ `kills` 永远为空。
