## 3. 关键设计决定

1. **诚实入池**：首发池只放**已准入**车；样车进实验池；延期车只登记不入池 → 不靠车名宣布对等。
2. **事实/调校硬分离**：两表键名互斥（套件断言），事实值直接取 `LoadingMechanism.VEHICLES` 交叉核对。
3. **阻断项即证据**：M1A1/ZTZ-99A 的阻断项来自仓库实测（内容树无条目、模型未整合、无模型），不是推测。
4. **样片自限范围**：`not_a_gunnery_duel=true` + `modern_in_normal_match=false`，把"现代能力未进正常对局"写成可核对的字段。
5. **共享遮蔽对象复用**：样车的传感器与 WT-017/WT-018 的烟幕规则同一来源，避免第二套可见性实现。
6. **体验门不代签**：无真人反馈即 `PENDING`（套件硬断言）。

## 5. 自纠记录（我的缺陷，4 处）

1. `var ok := thermal.ok and ...` → 字典字段为 Variant，GDScript 视作错误 → 显式 `bool`。
2. `var smoke := ...get("smoke")` → 同样问题 → 显式 `Variant`。
3. 侧翼场景按已废弃的 `main_push` 标签统计进攻道 → WT-019 修正后该标签不再存在；改为 `central_hook + secondary_push`（真实进攻道口径）。
4. 烟幕撤退场景假设样车自带烟幕发射器 → 实测**样车未配置**；改为"由支援车布烟 + 记录 `no_smoke_capability` 缺口"，并把它写进缺口表。
均未放宽验收断言（入池/阻断/事实分离/体验门/配弹影响库存始终为硬断言）。
