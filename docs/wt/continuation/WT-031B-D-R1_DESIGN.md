## 3. 关键实测结论

1. **无 `.import` ≠ 不可解析**：四个 GLB（含两辆研究模型）**全部**可由 `GLTFDocument` 解析。
2. **外形与单位是真尺度**：9.424 / 9.642 / 9.786 / 10.882 m，单位判定均为 `m`。
3. **真正缺的是角色名映射**：6 角色仅 **8/24** 解析；`m1a1.glb` 只有 7 节点/3 网格（合并 LOD）。
4. **可行动路径**：把 `modern_model_mount_adapter.gd` 的声明从 3 项扩到 6 个绑定角色 → 两样车可产出完整绑定；M1A1 需作者重导出带角色的版本。
