# 正常战斗 HUD：车体内构与损伤分色

用户要求：战斗界面显示车体内部结构和真实状态，并用颜色区分损伤。本次已接入正常 `BattleUI → BattleHUD`，不是仅在车库或开发检视器中展示。

## 行为与数据

左下角保留乘员数量、岗位空缺和驾驶状态，新增固定宽度的内构图。`VehicleDamageView.sample` 只读取本车已安装的 `VehicleLayoutDefinition`、模块状态、乘员岗位分配和库存；各面片与受击盒使用实际运动部件的当前世界变换，再转回车体坐标。炮闩/炮塔乘员跟随炮塔，发动机留在车体，左右履带跟随各自行走部件。无需为每辆车另画状态图，当前历史四车与现代两车复用同一适配器。

图形为真实布局的等轴投影和透视式线框外壳，Canvas 绘制模块有向盒；不是装饰图标，也不是新增一套有物理行为的车辆实例。正常比赛只传入玩家本车，不读取或公开敌方内构。每 0.1 秒刷新，换 Actor 时立即更换数据；绘图不推进维修、伤害、库存或比赛时钟。

| 状态 | 表示 |
|---|---|
| 完好 | 灰青色 |
| 轻损 | 黄色，模块剩余比例 0.67 至不足 1 |
| 重损 | 橙色，剩余比例 0.34 至不足 0.67 |
| 危急 | 红色，剩余比例大于 0、低于 0.34 |
| 失效 | 黑色、红色边缘及叉号，剩余比例 0 |
| 乘员 | 可用岗位浅青色和圆点；失能黑色/叉号，空位淡化 |
| 空弹架 | 根据实际 rack 库存淡化体积，不表示仍装满炮弹 |
| 起火/维修 | 实际起火模块标“火”，正在维修的目标显示圆环 |

颜色档位是本项目显示规则，不改变模块功能阈值。当前乘员状态是可用/失能，没有伪造尚未实现的轻重伤阶段。野战维修按现有规则恢复到 50% 时仍显示橙色，不假称全新。正常视图最多列四项模块文字，Tab 总览保留全部，图中仍绘制全部模块；换车时旧模块文字隐藏。

参考了战争雷霆以模块和乘员状态反馈损伤、以橙/红/黑表示不同损伤状态的方式；本项目独立实现布局与配色，不复制其图形资产或宣称完全等同其机制。[官方 Wiki：Ground vehicle modules](https://wiki.warthunder.com/mechanics/4775-ground-vehicle-modules)
