# WT-006 车体与移动碰撞节点拆分

开发基线 `be70f94`。这是悬挂行程接入前的生产结构调整，**没有启用自动压缩，也未新增玩家可用操作**。

TankVehicle仍拥有移动碰撞、接地查询、动力与落地回弹；新增HullFrame作为装甲车体、炮塔、相机与模型的共同父节点。QuerySnapshotBuilder的hull变换、DamageTrainingLayout部件解析、历史车型和M4工程模型均读取这一节点。重置清空相对位移。炮塔炸飞仍使用实际TurretRig，恢复时挂回HullFrame，避免死亡重置后绕过车体节点。

历史履带动画仍从TankVehicle实际运动读取速度/位移，模型查找改到HullFrame下；M4工程履带动画也保持读取真实车辆。历史车库预览使用自己的模型节点，不被强制加上驾驶行为。殉爆炮塔源码变更后只更新资源清单中对应的规范化源码哈希。

当前HullFrame默认单位变换，因此正常驾驶姿态、射击、现有点头与回弹仍走原路径。履带可见几何和track模块目前仍随hull，不可直接启用车体压缩，否则履带会一起下沉。下一步必须把履带支撑节点/模块变换独立出来，并在启用动态相对位移前补内部快照与网络相对车体状态。不能把这次节点拆分说成完整悬挂或支撑系统已完成。
