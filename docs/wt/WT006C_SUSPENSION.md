# WT-006C：有行程限制的地形悬挂

2026-09-12，开发基线9d7de40。本批在M4A3、M24生产驾驶路径启用四支点悬挂，WT-006与完整游戏仍进行中。参数是游戏设计值，不冒充车辆实测数据。

## 实现边界

移动仍由TankVehicle的CharacterBody3D碰撞求解器执行。每个固定物理步移动完成后，GroundProbe从左右履带各前后两个休止点读取真实WORLD地面；射线以drive休止坐标为基准，避免上一步悬挂变换反馈到测量。支撑要求移动求解器确认接地，地面还必须在该车可用行程内；能射到沟底不等于能够提供牵引。

SuspensionResponse保存四点位移、速度、目标和前一步drive变换。车体通过临界阻尼响应跟随地面，用相邻步drive运动修正惯性，并限制行程、速度与倾角；持续爬坡的阻尼相对移动基座计算。实际落地的入射速度触发一次压缩响应，停车收敛。腾空时行走机构伸展到下限，车体恢复休止位置；重生清除积分状态，暂停冻结。

HullFrame变换直接作用于车体外观、炮塔、炮口、装甲和内构查询。左右TrackFrame分别跟随各侧地面，受击模块使用同一实际变换。内部SimulationSnapshot包含版本1的悬挂积分观察状态和独立数组副本；不是完整恢复存档。网络沿用协议2/相对姿态1，只传服务器求解后的姿态，客户端插值显示，不运行本地悬挂。

| 配置 | M4A3 | M24 |
|---|---|---|
| 车体向下压缩限值 | 0.18m | 0.16m |
| 伸展限值 | 0.30m | 0.30m |

| 入射速度响应倍率 | 0.28 | 0.28 |

这是四支点运动学近似，每侧行走机构为一个刚性姿态，不是逐轮/逐履带节的载荷或独立刚体模拟。drive碰撞包络仍独立于车体小行程；旧制动点头和受限落地回弹继续由原drive路径负责，本次不增加第二套移动求解器。M26、M36以及旧工程教学配置暂不启用弹簧，不能据此登记全部车型完成。
