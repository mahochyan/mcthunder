# 河谷枢纽实地驾驶增量 — 2026-09-13

基于 `2724b27a`。上一轮完成三占点设计与环境勘察，本轮将大地图接入真实车辆驾驶、瞄准、射击、暂停和返回流程，并补充物理掩体与关键通路。**最多三个占点**和全部 42 项主线范围保持。

## 现在可以操作的内容

车库 → 训练中心 → **河谷枢纽 · 实地驾驶**。使用车库所选的现有车辆，按原操作驾驶、瞄准和射击。暂停菜单可选择部署位置，以及 10v10 / 16v16 活动布局；选择后仍保持暂停，点击继续才恢复操作。

10v10 布局提供内侧三处河道通路、两处部署场和三个占点附近的驾驶位置；16v16 增加两条外侧通路。两种配置都只有 A 采石场、B 货运站、C 河畔镇三个占点，其他地标不计分。

这是单车实地驾驶。没有生成 20 / 32 人房间、计分对局或奖励，没有绕过苏德候选车辆的准入限制。三点占领结算、团队容量和网络仍待后续接入。

## 实现

- `RiverJunctionRange` 复用 `BallisticsRange` 的真实 `VehicleActor`、`PlayerController`、车辆阶段调度、炮镜、`Gunner`、弹丸管理器和暂停流程。`AppFlow` 传入车库选择的车辆；没有另造轻量替身驾驶器。
- 暂停菜单切换地点会取消本车在飞弹丸、重置装填/机构/待发输入并建立新的复位点。切换布局会放置到该布局中央通路。越界或进入深水持续 5 秒后回到所选部署点，并有倒计时提示。
- 增加 39 处具备真实凸体碰撞的防御土工结构，覆盖部署场前方/两侧、桥头和转场区域；生成器避开建筑，并保留土工结构之间必要连接。
- 部署泊位改为交错两排，后排不再暴露在侧向视线缺口。跨河试驾位置对齐桥面中心。
- 桥梁基础延伸到两岸平整道路下方，避免粗地形三角插值与桥面端部形成卡底盘接缝。可见桥面长 104 m，基础总长 160 m，两端埋入路基。
- 建筑壳体增加匹配山墙轮廓的屋顶碰撞；桥梁路缘和横向护栏、树干有真实碰撞。树冠与大部分小装饰仍不承担硬掩体判定。
- 地形物理体按实际道路条带报告 road / grass，桥面为 concrete，土工结构为 soft_soil；使用已有驾驶表面参数。城镇主街与院落/试驾位置对齐。
- 驾驶战术图随车辆更新；远近裁剪调整只作用于该地图驾驶相机。

## 验证范围

`tests/run_river_driving_checks.gd` 从正常车库进入，使用 M4A3 生产车辆。无窗口检查五条跨河通路的完整行驶、接触高度和侧向余量；还检查部署场东西两条出口、镇内驾驶、暂停冻结、部署切换、复位、射击扣弹、越界回收及正常返回车库/存档不变。该脚本使用固定模拟帧进行功能测试，不测帧数。

实际窗口入口使用鼠标事件，跨桥和城镇驾驶使用 W 键事件；布局/地点选择通过实际 OptionButton 信号执行，射击通过真实 Input 动作进入生产控制器。不得把自动操作记为真人试玩。

物理射线验证双方全部 10 / 16 个泊位的落地空间，并从三个占点各一个 4 m 观察高度向泊位车顶采样：60 + 96 = 156 条射线。这仅证明这组采样被遮挡，不代表全部地图位置、炮镜高度、空中视角或占点外绕后路线均不可压制出生区。

最终数目、命令模式、日志与截图见 `logs/WT032-driving/RESULTS.json`。旧车库交接、应用加载/返回与勘察布局另做关联回归。
