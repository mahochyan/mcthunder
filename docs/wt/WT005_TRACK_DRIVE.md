# WT-005 差速转向第一步

2026-09-11：用户明确要求性能优化暂到当前版本，继续主线开发。保留WT-003未达标项，暂停其追加优化/完整局采样。开发基线867a89d。

生产TankVehicle.apply_drive接入每车独立TrackDrive。按当前前进/倒车速度与对应限速的比例降低偏航角速度；转向阻力按转向输入、速度比例与时间指数衰减纵向速度，再由既有动力系统推进。直行不额外扣速，倒车不改变速度符号。左右履带速度按车体纵向速度与偏航差速计算；车体方向由同一偏航率推进，重置清空全部履带状态，原有驾驶/转向能力限制继续生效。

DriveProfile新增turn_speed_falloff、turn_drag_per_second、track_spacing_m、neutral_turn并验证有限数值及范围。M4设计曲线0.5/0.45/2.6m，M24为0.3/0.25/2.4m。全部为游戏设计参数，不是历史传动/履带间距实测值。默认原地转向资格继承旧玩法；关闭时偏航随低速趋零。逐车型资格与手感尚未签收。

当前履带状态是差速运动学目标，不是左右独立地面接触/侧滑求解，撞墙后的真实履带打滑也未模拟；不能把它直接当实际接触位移驱动最终履带动画。单侧履带失能/维修后的差速限制尚未接入，旧能力规则仍是一条履带失能即可整体禁行。WT-005保持in_progress。
