## 一、生产阻断：水平目标角算反了（已修复）

GPT 独立数学复核：本工程炮管 -Z 前向、右手系、无镜像 → 前向 = `(-sin yaw, 0, -cos yaw)`，
目标角应为 `atan2(-d.x, -d.z)`；旧代码 `atan2(d.x, -d.z)` 符号相反。
反例：d=(10,0,-10)（右前方）→ 旧公式 +45° → 炮管指向左前方；正确 -45° → 右前方。

修复（`scripts/turret_rig.gd`）：
- 抽取共用函数 `_target_angles(P) -> Vector2`（pitch, yaw_global），**正常追赶与 snap_to_aim
  两条路径共用**，杜绝再次分叉；
- 世界 yaw = `atan2(-d.x, -d.z)`，再扣除车体 yaw 得局部角；俯仰限位与有限转速保留；
- 未反转鼠标、未镜像模型、未挪靶板、未改用相机判伤。
