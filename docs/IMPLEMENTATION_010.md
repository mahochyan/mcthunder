# 010 实现方案
009登记d85f3c0后继续work/010-shot-replay，固定引擎与用户持续开发授权有效。

- ProjectileManager在实际推进点采集有界路径，在真实接触前从本物理步快照冻结目标外甲/模块/乘员几何及部件姿态。每条接触/损伤记录引用自己的geometry_frame，不能拿后来车辆姿态回填。
- ShotRecordBuilder在终止前后明确身份边界：先终止/移出活动，再冻结schema/rules/seed/launch/path/contact/damage/terminal并放入有界Store，最后通知显示。回调重置不能让旧记录进入新局；取消记录不自动播放。
- 路径最多512点、几何帧最多96、每帧几何规模与记录JSON大小有上限；超出时仅令回放明确不可用，不能改变真实弹丸结算。Store默认16条，只返回副本。
- ShotRecordCodec只处理明确JSON基础类型与Vec2/Vec3/Transform3D数组编码；拒绝Object/Resource、非有限数、非法索引、未知schema/rules和过深/过大载荷，不使用对象反序列化。
- ReplayView是独立SubViewport/world_3d纯显示节点，只有Mesh/Camera/Light，无车辆脚本、碰撞、AI或武器。按记录采样位置重播，只有真实损伤项被高亮；未穿/跳弹沿真实折线路径停止/折返。
- 各训练场正常射击后自动显示右下角约3秒窗口；V关闭/重看，逗号/句号浏览有界历史，N依次选择真实接触/部件，J导出当前单炮JSON到user://shot_records。回放不暂停训练或消费左键；键位不抢准星。新增开关放暂停菜单，记录仍正常生成。
- 场景重开/退出清缓冲和显示；真实目标后来移动、转塔、损毁或删除均不改变回放。尚无正式战斗，训练允许全部真实命中记录；未来正式战斗必须由权限入口显式批准显示。
- 自动检查覆盖10次重播无副作用、目标变换/删除后冻结姿态、未穿不画入内部、JSON往返/非法拒绝、缓冲/场景释放、正常窗口射击与回看。错误记录显示原因，不编造结果。
