## 必须有（PASS 项 = 逐项目检）

### 炮塔（大、前置、圆润铸造切面感）
- [ ] T1 铸造多面体炮塔：前窄后宽带尾舱，立面外扩后收顶（12 边形放样级别）
- [ ] T2 车长舱盖：炮塔顶后部矮圆筒 + 盖 + 把手（偏中线）
- [ ] T3 炮塔顶前角 2 个小矩形凸起块（左右各一）
- [ ] T4 炮盾：铸造圆形盾 + 炮根圆筒套环；盾右侧垂直观察狭缝（暗色）
- [ ] T5 主炮：**光身长管、无任何制退器**，炮口轻微台阶加粗
### 车体
- [ ] H1 大倾角首上 + 前下鼻板折角（T 型断面）；侧板上部内倾（倒梯）
- [ ] H2 驾驶员观察塞：首上左中圆形凸起塞盖（带矩形玻璃缝）
- [ ] H3 变速箱检修盖：首上中右矩形微凸面板 + 顶部 2 个小拉杆
- [ ] H4 首上 D 形拖钩 ×2（一高一低斜置，3/4 图左高右低）
- [ ] H5 大灯 ×2 带护罩，立于两侧前翼子板上
- [ ] H6 翼子板/挡泥板（带侧裙过渡、边缘切角）
- [ ] H7 发动机甲板：右侧条形百叶格栅（斜板条）；后视大矩形盖板
- [ ] H8 **圆柱形副油箱 ×2**：两侧翼子板后段各一，横置、双抱箍
- [ ] H9 木箱 ×1（甲板中右）+ 长柄铲 ×1（木柄+钢铲头，贴甲板）
- [ ] H10 侧置排气管 ×2（后段甲板两侧、微上翘）+ 后视排气口
- [ ] H11 车尾 D 形拖钩 ×2 + 后下双排气口暗色
### 行走（克里斯蒂式）
- [ ] S1 **负重轮 5 个/侧**：大直径(≈Ø0.8)近相切、光橡胶胎圈 + 橄榄盘面 + **6 螺栓圈(几何)** + 中央毂盖
- [ ] S2 **前置主动轮**（齿块 ≥8、上置）；S3 后置小诱导轮；**无托带轮（不得加）**
- [ ] S4 单节履带全环（含上直线段）：深色块节 + 中央导齿凸起
### 涂装/标记
- [ ] P1 橄榄绿两阶（上浅下深）+ 履带深灰 + 木件棕色
- [ ] P2 **无任何星标/徽记/天线/高机/铅笔管（不得多）**
