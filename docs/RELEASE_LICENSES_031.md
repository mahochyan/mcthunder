# 引擎与素材许可

Godot Engine 采用 MIT 许可，完整引擎与依赖版权文本由构建所用引擎导出至 `GODOT_LICENSES.txt`。

简体中文字体 Noto Sans CJK SC，SIL Open Font License 1.1，许可全文在 `FONT_OFL.txt`，并随游戏字体资源内置。

四款坦克运行时几何、场景物件及音效为项目制作。模型由 Blender 程序几何和人工调整生成，共享图集由 ImageGen 按用户概念参考生成；未直接提取 War Thunder 游戏模型、贴图或音效。来源与哈希随 `assets/*.json`、车型 `manifest.json` 和音频清单保留。原始 Blender 工程和开发参考文档不在发行包中。

车型名与史料引用用于说明配置，来源与游戏估算不是同一类事实。当前包仅供已授权的本地开发和试玩；用户提供参考图的来源权利仍由持有人确认，本文件不代替对外发布前的来源许可复核。第三方名称不意味着相关机构授权或背书。
