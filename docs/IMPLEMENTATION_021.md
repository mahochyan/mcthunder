# 021 实施方案

分支 `work/021-shell-loadouts`，基线 `02d3aea76bd12fb457d9bb52cabd8fefbeaf934f`。Godot 4.7.2 stable 普通版 Compatibility。基线源码无未提交修改；此前 WIP 日志和截图保留原归属。

1. 扩展 009 AmmoInventory 为按弹种记录的唯一账本；旧整数视图由账本计算。装填中选择不改变已搬运弹，已入膛弹固定；正式配弹与补给遵守车载总容量和各架容量。保留旧单弹种工程夹具适配。
2. 接入 VehicleCommand.select_shell 与按键 1/2；实际 Gunner 冻结膛内 ShellDefinition。无选中备弹时停止取弹，选中有备弹的弹种可开始正常装填；不清冷却、不免费换膛。
3. APHE 是明确标记的游戏内部爆发规则：穿入目标后累计 0.8m；提前穿出则取消该次目标爆发并继续动能路径。最多 12 条带种子的射线，每条有限长度/查询次数；装甲和模块使用生产查询/阻力入口，不递归、不广播。内部爆发终止母弹。
4. 记录实际爆发点、破片路径、装甲/模块结果，回放只显示记录。正式历史弹种适配与性能独立核验；不把 AP × 0.8 当作历史数据。该比例仅用于明确 TEST ONLY 比较靶场。
5. 验证未穿/早出/厚甲拦截/空舱/数量预算、配弹切换补给重生守恒、记录重播一致与正常玩家入口；运行相关及完整回归和真实窗口演示，人工试玩状态独立。

021 不实现真实引信、爆药参数、网络或 022 研发系统。实现期间发现的源码问题在本单修复，证据保留真实失败及修复结果。
