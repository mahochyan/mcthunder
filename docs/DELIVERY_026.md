# 026：战斗声音与可调反馈

13种原创合成声音接入真实驾驶、射击、装甲接触、装填、火灾和死亡；声音池保留关键事件名额，提供战斗音量、特效档位和震动强度。真人试听和重量感接受仍NOT_RUN。

## 实现与边界

CombatFeedback由实际ProjectileManager拥有，Gunner在扣弹与发射提交后通知；命中读取实际接触/终止记录，死亡读取已提交事件。按发射/生命/接触身份去重，保存最近512个事件键，不订阅回放。发动机音高随车速变化，履带也响应原地转向，炮塔音随真实转速，起火随实际模块/残骸状态。没有声音或视觉对战斗状态的反向写入。

每场固定32音源：24循环、8事件。关键事件可替换低优先级事件，机械循环不会占用射击名额；240米外不播放。源增益有界，Combat总线前级18dB、硬限制−1dB，实际录音再独立检查削波。末次击毁声可自然结束，终局立即停循环；暂停停全部声音，恢复只恢复当前循环，离场释放整个池。

弹着粒子池12组、每组最多8粒、寿命0.5秒，无碰撞。关闭特效同时隐藏炮口、飞弹标记、残骸烟火及建筑烟尘/碎屑；低档减少粒子，装甲查询、伤害与回放记录保持原规则。光学震动强度0—1，炮镜仅20%；默认稳定镜头。Esc→显示与辅助内调整，会话外保存由029统一处理。

音色由authoring/build_audio.py确定性生成，不使用其他游戏录音；assets/audio/manifest.json保存来源和逐文件哈希。详细预算与引擎接口来源见[AUDIO_FX_026.md](AUDIO_FX_026.md)。

## 已处理问题与限制

初始合成声音电平偏低；实际录音分析后提高总线前级并设硬峰值限制，再录制验证。固定帧率快速退出可能早于音频线程排空；生产池退出时停播并释放流，专门无窗口音频测试在退出前等待100ms处理后台停止队列，最终无残留警告。

早期正常设置演示失败源于自动滚动辅助将滚轮落在音量滑块上，确实把音量改回零；最终按正常Esc返回设置菜单，重新验证实际滑块值和音源播放。不是通过直接写设置值伪造演示。早期致命夹具未启用恢复/殉爆规则，修正夹具配置后按真实炮弹重测；没有放宽伤害断言。资源包测试补充显式bool类型，修正解析失败后重跑通过。

模拟声音为原创合成风格，未宣称历史录音真实性；音色可辨识度、声音舒适度和镜头手感需真人意见。继承AI交通与长帧、无弹失能后维修边缘问题；90秒八车录音不冒充整局性能验收。下一步027中文、输入改绑与基础易用性。
