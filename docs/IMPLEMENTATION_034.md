# 034 实际发行程序回归方案

最终验证锁定包内 BUILD_MANIFEST 的 source_sha、EXE/PCK SHA256，并在独立目录执行，不把旧开发测试拼接为同一 RC 的证据。031 全新构建覆盖全部源码回归与两图驾驶、改绑开火、四车材质、中文字体、三挑战和教学入口。

`--verify-player-flow` 另外使用真实 Release 入口、隔离档案和普通键鼠完成侧击挑战，验证实际穿透归因、三星/个人最佳写盘、重新打开 ProfileStore、回放、挑战重试与放弃。随后通过车库普通模式按钮进入两图，等待真实计时/票数自然结束，验证冻结结算、一次收据、读盘、重开和确认返回。玩家车辆在这两局中静止并按正常接口申请重生，不伪称模型进行了真人战术试玩；此前侧击挑战负责键鼠驾驶/瞄准/射击证据。

所有自动截图来自同一窗口。每次挑战开始会通过 Esc 解除可能的失焦暂停并等待真实倒计时；不改冷却、弹药、乘员、死亡或票数。无人参与的测试仍明确标为自动验证。

`tests/run_player_flow_checks.ps1` 验证传入 SHA 与包清单一致，保存命令、退出码、截图哈希和缺失截图。必须包含车库、真实回放、两图战斗和两图结算图；失败时不输出成功报告。

陌生玩家从 ZIP 自行启动、理解失败原因和接受手感的部分保持 PENDING。多机器、不同 DPI、只读文件夹 ACL 和其它显卡需要实际执行后才能填 PASS。
