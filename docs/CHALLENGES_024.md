# 三个固定挑战 · 规则 v1

车库底部“挑战任务 / 个人最佳”打开选择页。标准与困难各有独立成绩；所有任务开放规定的训练车型，不改变正式研发解锁。倒计时3秒，无补弹、再出击或研发点奖励。Esc暂停/返回，R结束当前尝试并重新创建场景，结算后V查看真实弹道回放。

| 任务 | 标准 / 困难 | 完成条件 | 第二星 | 第三星 |
|---|---|---|---|---|
| 侧翼猎手 | M4，6 / 4发M61；180 / 120秒 | 真实侧/后装甲穿透，并归因于玩家击毁静止M4靶车 | 用弹≤2发 | 用时≤80秒 |
| 阵地坚守 | M4，8 / 6发M61；210 / 150秒 | 工业仓库西防区累计35 / 45秒，同时击毁两波各一辆M4 | 实际完成一次受损模块维修 | 用时≤140秒 |
| 猎歼突进 | M36，6 / 4发M77；180 / 130秒 | 依次通过两个道路检查点，再连续占据中央点15秒 | 用弹≤2发 | 用时≤100秒 |

完成基础目标取得第一星，其他星必须同时满足各自条件；失败与退出为0星0分。分数为星级×10000 + 剩余秒×10取整 + 剩余初始配弹×100。计时以毫秒取整后评定与存盘，界面说明和评分读取同一ChallengeCatalog。只保存较高总分的一份最佳记录，其用时/炮数是该记录对应值，不冒充另一份独立“最快时间”。

侧翼靶车没有AI、不还击，明确是装甲训练靶。它使用真实历史M4装甲；正面斜甲较难穿，仍可能存在可穿部位，任务要求额外确认侧/后穿透。射击穿深、APHE破片与内部模块不是任务专用计算。

防区中心(-78,100)、半径18米；离开或有活敌车进入时停止累计。两波有限敌人分别携带8 / 12发M72，使用普通 / 困难AI感知、反应和瞄准误差档；不修改武器、装甲或驾驶性能。第二波主出生点(-95,25)，另有(-95,50)、(-95,75)两个公开设计候选。每次检查实际车体/世界碰撞，全部受阻时每秒重试一次，并在目标栏显示等待清空道路。最多玩家加两个敌车/残骸，没有无限刷怪。健康时按T、取消维修或重复提交旧完成事件不计维修星；受损必须来自真实战斗，不以脚本直接扣模块制造剧情。

路线检查点(-72,50)、(-42,20)，各半径8米；中央据点半径12米。检查点必须依次通过，提前进入中央点不计时；离开或被活敌争夺会清空连续占领时间。守卫M4携带4 / 6发M72，使用对应AI档。路线任务没有“弹药为零必败”，因为任务允许在已排除争夺后用最后的无弹车辆完成占领；需要击毁的另两项任务则在弹尽且在途弹全部终止后判断失败。

## 权威数据与持久化

ChallengeRange只装配已有地图、VehicleActor、Gunner、ProjectileManager、DamageResolver、VehicleRecovery和AITankController。任务只决定初始位置、配弹、有限波次、区域和目标，不改真实伤害。ChallengeDirector以独立attempt_id及player life/generation绑定本次尝试，在管理器之后的物理步读取实际死亡归因、区域位置和已提交射击记录。记录必须已存在于实际ShotRecordStore，record_id去重；敌车必须匹配登记的life/generation。维修记录在VehicleActor实际提交恢复后产生，以life/generation/序号为身份，前后完整性确有提升才发布。

ChallengeProgression绑定真实Director，结算接口不接收外部构造的结果。已完成结果冻结后才进入待保存队列；重复回调不再次保存。ProfileStore的schema2新增有界challenge_bests（3任务×2难度、规则v1），显式将合法schema1补空表，随后执行完整校验。目录不可写或事务失败时保留原档及已验证结果，返回车库后仍可重试。成绩键包含任务、版本和难度；未知版本的记录不会混入v1。当前没有战斗快照、剧情进度或隐式奖励。

## 证据边界

自动检查包含明确标记的数学/起始姿态夹具，以及不改敌方AI的脚本驾驶集成；所有射击、维修和移动都走共同生产链。正常窗口演示使用车库按钮、键鼠驾驶/瞄准、自然装填和真实结果保存，独立于这些夹具。最终命令、源码、截图与结果见DELIVERY_024.md；真人状态单独记录，不能用自动演示代签。
