# 首版候选与后续细节工作

当前主线以 Windows 离线四车、两图、4v4 AI 占点、两类弹药、三挑战、教学、中文车库/设置/存档/结算和独立包为边界。更大的战争雷霆内容规模没有悄悄并入“完成”定义。

| 项目 | 当前实现 | 后续范围 |
|---|---|---|
| 开炮后坐 | 枪管视觉后坐、开火反馈和已有火光/声音 | 车体随炮塔方向受冲量，侧射侧倾/回弹，弹簧阻尼悬挂 |
| 驾驶 | CharacterBody3D、速度/转向限制、地面姿态、碰撞与坡地 | 真实履带链、路轮/履带悬挂物理解算 |
| 坦克模型 | 四个历史配置的原创 low-poly 运行模型 | 99A 作为额外车型需要独立定义、装甲/内构/弹药/玩法集成，不能只替换外壳 |
| 99A 制作成果 | 原工作树有高模和约4000/2000/1000三档烘焙模型包 | 以99A多视图为主的外形真人验收、进一步炮塔还原 |
| 毁伤 | 有限弹速、多层装甲、模块/乘员、维修/起火/殉爆、实际记录回放 | 更细致材料/弹药模型和逼真动态变形不属于本首版 |
| 美术表现 | 原创低面数场景、13种合成音效、有限特效池、残骸展示 | 车体运动/炮口烟尘/冲击波/地面扬尘的统一细节优化 |
| HUD 与结算布局 | 中文控件、统计和退出可用；最终 720p 截图可复查 | P2：结算页短暂被战斗字幕覆盖统计行；收拢战斗 HUD，减少本车画面遮挡 |
| 中文角色标签 | 主要界面与操作提示已本地化 | P2 UI-L10N-RC2-01：正式长测工业图中“assistant driver bow gunner”乘员标签仍显示英文，需补充角色映射 |
| 性能 | RC2连续1876秒/20生命周期/67项检查通过，平均51.86FPS | P2 PERF-RC2-01：村庄43—48FPS，存在2.65秒最大帧尖峰；先补逐帧定位，再优化查询/AI/加载，保持黄金毁伤一致 |
| 对战规模 | 本地玩家和AI，八辆活车，单据点 | 联网、航空/海战、更多地图模式和大型科技树 |
| 验收 | 工程自测、具体机器与候选包验证分别留证 | 陌生玩家上手、用户1.0接受、跨机器性能与公开权利核验 |

主线收尾以后先定位村庄帧尖峰、改善HUD与动态角色中文，再按用户指出的侧面射击、车体后仰/侧倾与火光整体表现推进物理反馈。接入车体冲量和悬挂时保留现有规则与黄金命中记录，不把纯动画改名为真实刚体物理。
