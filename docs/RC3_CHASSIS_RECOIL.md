# 方向性车体后坐（开发批次）

用户目标已扩展为：完善游戏完整性、可玩性，越还原战争雷霆的玩法和设计越好。此次工作先补足射击时车体完全无反作用的问题；目标仍在推进，未声明整个游戏完成。

## 实现

Gunner 仅在实际弹体发射成功、扣弹提交之后施加车体反作用。TankVehicle 使用独立世界空间 recoil_velocity，沿实际炮管方向的反方向作用，并投影到支撑地面；不写入油门速度。速度与驾驶共同经过 move_and_slide，受世界及车辆碰撞阻挡，不能通过直接修改坐标穿墙。暂停冻结，重置清除，受碰撞阻挡的速度分量被移除。

GameConfig 集中设置初值 0.65 m/s、阻尼 5/s、叠加上限 1.3 m/s。使用指数衰减积分。它是 CharacterBody3D 上的简化车体反应，不是刚体质量、悬挂弹簧或历史后坐力还原；未实现俯仰/侧倾/路轮悬挂。发射位置及弹道先冻结，再施加后坐，已发射弹体不被追溯修改。

## 实测

`tests/run_chassis_recoil_checks.gd`：23 项通过，日志 `logs/rc3-chassis-recoil-r3.log`。通过真实 VehicleCommand 发射四个方向，实际车体移动约 0.128 米；冷却拒绝不叠加后坐；暂停冻结；重置清除；墙后退距小于 0.07 米。改变实际 Engine.physics_ticks_per_second 为 30/60/120 后，两个仿真秒内距离均约 0.127984 米。

第一次多频测试错误地只改变 apply_drive 的参数，而 move_and_slide 仍使用引擎固定物理间隔，导致距离按频率成倍变化。失败日志 `logs/rc3-chassis-recoil-final.log` 保留；已改为改变真实引擎频率并等待真实物理步，未放宽 2 毫米误差要求。

相关回归在 `logs/rc3-recoil/wip/20260911-102235/RESULTS.json`：基础 216、驾驶 25、AI 战斗 34、弹体 144、装甲 81 项通过。弹药测试原有两个停车补给断言失败，因为刚开炮后的车体不再静止；新增“后坐期间不能补给”断言，并等待车体自然停稳再计时。补给规则没有放宽。修正后复测见 `logs/rc3-recoil/wip-r2/`。

测试为开发工作树验证；未替代整局性能、完整黄金矩阵、真人手感和新发行包验收。实验室退出仍有 ObjectDB 警告，保留为待排查。

## 接续方向

在现有模块毁伤、乘员、弹药、维修、占点与车库基础上，继续补驾驶重心和侧倾反馈、独立观察/炮镜操作、测距与射击解算的玩家操作深度，再改善地形掩护与 AI 战术。每一步需要实际操作、碰撞/命中一致性和完整流程证据，不能只增加按钮或展示动画。优先维持现有游戏可运行与性能，未实现的项目继续记录为未完成。
