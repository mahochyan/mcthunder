# 026实施计划：声音、特效与重量感

基线025登记19c291ccfbc23d43c5f849310c1eb67b752b082c，远程同SHA已核对。分支work/026-audio-fx，Godot4.7.2.stable.official.ed1daf0bf、Compatibility。未提交文件为既有诊断输出、预览和便携模型包，不改写这些结果。已读根AGENTS、原WO026、增强交接026、执行协议、架构契约与规则。

1. 用项目原创确定性合成脚本生成发动机、履带、炮塔、射击、飞行掠过、装填、未穿、跳弹、穿透、起火和殉爆音色，记录生成器、哈希、许可和音量。游戏不调用外部服务。
2. 场景拥有统一声音/效果表现器，订阅实际发射、接触、伤害和死亡，或只读实际连续状态；按完整生命/发射/事件身份去重，不订阅回放再次结算。发动机/履带由实际车速驱动，炮塔由实际转动驱动。
3. 声音池限制总数、距离和增益，关键射击/毁伤优先于引擎等循环；专用音频总线和音量设置。暂停、失焦、比赛结束、切场景立即停下循环，重生清除旧生命。不得在菜单漏播。
4. 保留已有炮口/后坐/残骸机制，增加有界弹着火花/烟尘；低效果/关闭效果不动伤害、射线和计分。镜头只作显示偏移，强度可调至零，炮镜衰减；真实炮口和瞄准来源不变。
5. 实测固定伤害与胜负在静音/禁效果/禁震动/禁回放下相同；真实100发及重生后的节点预算、事件去重、暂停/切场景清理。八车真实窗口测音频峰值和池占用，另走正常玩家入口、显示设置与自然射击流程；听感接受仍需真人。

相关回归、资源包导入与实际抓帧完成后登记交付；不把无窗口测试称为已试听或重量感验收。
