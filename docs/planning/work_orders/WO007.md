## 2. 实现步骤

1. 实现可单测 ArmorResolver：按入射方向与法线计算夹角，先处理掠射和跳弹，再计算视线厚度 t/abs(dot)。这只是游戏近似，不宣称真实材料穿甲公式。

2. 读取 ShellDefinition 的距离—穿透曲线，分段插值，约束范围。统一“累计穿透消耗”而不是每遇到一块板恢复满穿深。

3. 击穿记录消耗和余量，继续通过空舱、下一块装甲或世界物体；首版无穿甲弹爆炸伤害，也不能越过未击穿面。

4. 先用简化的 75 度跳弹阈值、最多一次有效反弹，反弹方向和穿透折损由游戏配置控制；边界比较、残余不足、背面命中等必须有文档。

5. 防止刚穿过同一零厚度逻辑面被再命中；使用交点去重/容差和上限，不排除整辆敌车。

6. 在调试界面展示面 ID、厚度、夹角、等效厚度、入射可用穿深、剩余量和停止原因；正式 HUD 先只显示未穿/击穿/跳弹。
