## 2. 实现步骤

1. 以已完成中型车为模板新增轻型侦察车、重型突击车、固定战斗室歼击车；共4款，而不是再新增4款。名称和外观原创、性能全部标为架空游戏值。

2. 按 VEHICLE_SEEDS.json 的初始方向配置：轻车机动好但薄甲，重车防护好但转向慢，歼击车前向火力好但射界窄，中型均衡；具体平衡留032实测。

3. 每车必须配齐外观、行驶碰撞、装甲面、真实内部布局、炮口/旋转轴、弹药架和配置校验，不允许只换颜色或整车血量。

4. 歼击车的主炮限制左右射界，超过射界由车体转向完成；玩家和AI均使用同一限制，不为它复制另一套射击系统。

5. 已有车型不应因新增数据而被硬编码判断车型名称。确需接口扩展时写迁移测试，旧车型行为保持或明确批准修改。

6. 每车执行同一套射击、模块、驾驶、炮镜与出生通行测试。
