## 2. 实现步骤

1. 保留AP稳定穿透、较少车内扩散的特征；APHE设为较低穿深、成功进入车内后按游戏化行程触发内部爆发。不是工程级引信或爆药仿真。

2. 只使用可配置的玩具规则：击穿合格表面后起算车内路程，触发时有限条内部碎片射线沿生产查询服务结算；对装甲/模块的消耗规则统一，禁止穿墙全车广播伤害。

3. 碎片方向由种子决定，每枚最多12条，每条有距离/迭代上限，不递归产生碎片；已终结车辆不重复死亡。

4. 按键1/2选弹。当前装填结束前切换只影响下一次装填，已在膛内弹丸不会瞬间变种；弹药计数和弹药架实际分配同步。

5. 把有限备弹接入所有正式车辆；训练无限弹是单独规则，不能泄漏到正式比赛。无弹时开火不生成弹丸，也不进入虚假装填。

6. 回放显示实际记录的引爆点与命中碎片，不能随机画满整辆坦克。
