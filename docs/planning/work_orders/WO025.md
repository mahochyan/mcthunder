## 2. 实现步骤

1. 制定小型美术规范：方块化但保留斜甲和车型轮廓；统一材质粗糙度、调色范围、细节尺寸、光照和地面比例。名称与标志使用原创表达。

2. 优先复用程序生成/基础几何模型；确需Blender则仅引入可重复的建模导出脚本，并写工具版本和执行方式，不让用户手工摆几百个部件。

3. 四车型分别检查车体、炮塔、炮管、履带、炮口、后坐部件的命名和轴；显示模型、行驶碰撞、装甲面与内构采用同一尺寸基准。

4. 做少量可复用场景件：房屋、仓库、墙、石堆、树和道路；重要轮廓清楚，避免靠高频碎纹理掩盖方块风格。

5. 记录每个素材的作者/来源/生成方法/许可状态/用途；没有可说明来源的现成游戏资产不得进入发行包。

6. 每类模型先做一件确认再批量替换，替换过程中保留原代理形体作为调试参照，不同时大改伤害数值。
