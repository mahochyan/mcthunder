## 2. 实现步骤

1. 保留简化可控车辆运动，在测试场增加10/20/30度坡、低台阶、窄通道、墙角和凹坑。车体碰撞尺寸仍由车型定义控制。

2. 用地面探测控制贴地与视觉俯仰，物理车体朝向、视觉倾斜和炮塔瞄准坐标分开；避免视觉倾斜重复应用到装甲模块坐标。

3. 限制最大可爬坡角，默认28度；超过阈值不得贴墙上天。不同车型的坡度限制、前后速度、加减速集中配置。

4. 将发动机/履带状态通过统一能力接口作用于移动；断履带不是只播放动画。倒车和坡地停车有可预测规则。

5. 履带滚动/轮转只作视觉反馈；边界区使用可见障碍并提供只在彻底卡死时可用的重生入口，训练可重置，战斗重生必须按出局规则扣票。
