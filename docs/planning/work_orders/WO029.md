## 2. 实现步骤

1. 用用户可写目录保存数据：设置与个人战绩分开；设置可用ConfigFile，成绩使用有schema_version的简单结构。不要写到只读安装目录。

2. 保存音量、窗口模式、灵敏度、改绑、语言/字号、辅助选项；成绩只存教学章节、三项挑战星级、最佳成绩和有限场次统计。首版不存局中物理快照。

3. 采用临时文件写入、检查成功后替换并保留一份已知良好备份；针对实际平台验证替换行为，失败时不先删唯一旧存档。

4. 校验版本、类型、范围和ID白名单；损坏、缺字段、旧版本或未来版本使用明确回退/迁移，不从存档任意路径加载脚本/资源。

5. 设置改变后显示模式先预览，默认10秒未确认回退；防止选择无效分辨率后无法操作。

6. 提供重置设置与重置成绩的分开按钮，危险重置需确认；日志不记录私人文件路径、账号令牌等。
