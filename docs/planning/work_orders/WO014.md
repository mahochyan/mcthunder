## 2. 实现步骤

1. 定义巡逻/前往目标、观察、交战、搜索最后位置、撤退/维修等有限状态。每个状态只能通过统一 VehicleCommand 控制车辆和武器。

2. 感知使用距离、视野和遮挡检测；记住最后可见位置和时间，不持续读取墙后敌车实时位置来精确跟踪。队伍情报共享暂不实现或明确限定。

3. 瞄准具有反应时间、误差、有限炮塔速度与装填；可对暴露的车体/炮塔几何区域选择目标，但不得读取未揭露的内部损伤来作弊。

4. 用发射前炮口方向和友车遮挡检查减少误射；实际弹丸仍走同一飞行和伤害链。命中预测不能替代真实开炮。

5. 定义简单/普通/困难三档配置，差异只在反应、误差和决策间隔；同车型速度、穿深、装填、维修和伤害规则一致。

6. 引入带种子的决策随机源，并输出状态切换原因；不承诺整个Godot物理跨平台位级确定性。
