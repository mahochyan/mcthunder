## 2. 实现步骤

1. 核对最终源代码SHA、构建包SHA256、引擎版本、规则版本、资产登记和完整测试报告对应同一候选。必要时从该SHA重新构建并复测。

2. 按RELEASE_CHECKLIST逐项签收：4车、2图、靶场、2弹种、4对4占点、3挑战、教学、中文设置、车库、存档、结算、独立运行和已知限制。

3. Codex填写实现与自测证据；审核者填写技术检查意见；只有用户能填写“实机试玩接受”。任何角色不冒充另一个角色。

4. 默认只准备本地1.0包与标签建议；未经明确发布授权不创建公开Release、不上传发行物、不提交商店。已有源码推送授权按约定分支执行，不强推。

5. 记录后续修补流程：反馈→关联构建→复现→P级→小补丁→回归→候选包→用户接受→发布。保留前一可用包，存档迁移必须兼容或提示。

6. 把联机、飞机、海战、步兵、逐体素破坏、真实履带链和大科技树移到1.0以后独立提案，不为“完善”无限追加首发范围。
