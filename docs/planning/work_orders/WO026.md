## 1. 本单必须留下的可观察结果

让开车和交火有力度，同时确保反馈真实、可关闭且不遮住战斗。

## 2. 实现步骤

1. 补发动机怠速/加速、履带、炮塔、开炮、装填完成、命中未穿、跳弹、击穿、起火、殉爆等声音；使用可记录来源的资源或原创合成音。

2. 按实际车速和状态驱动发动机/履带，按距离衰减远处声音；设同时声音数量与优先级，避免8车场景削波和音源堆积。

3. 炮口闪光、后坐、烟尘、火花、火灾、残骸均订阅战斗事件；不能通过视觉粒子碰撞来另算伤害。

4. 镜头后坐与摇晃可调/可关；炮镜中保留清楚目标，不让持续烟尘完全挡住主要瞄准区域。

5. 区分击穿但未毁与真实击毁，禁止每次命中都播放毁车音。低画质可减少粒子，不改变命中和碎片射线预算。

## 3. 自动检查与集成验收

下面是要实际实现和运行的验收案例，不是已有测试通过记录。每个测试调用真实生产逻辑，记录源码SHA、命令、种子和结果。

**T026-01**：关闭声音、粒子、回放或镜头摇晃，固定测试伤害与胜负保持一致。

**T026-02**：连续开火100次和车辆重生后，音源/特效节点数量返回定义上限内。

**T026-03**：暂停、失焦、离开比赛后长音循环正确停下，无菜单里仍有引擎声。

**T026-04**：8车交火同时音量不过载，关键警报不会被低优先级环境音完全淹没。

还必须重跑此前相关回归、资源导入/脚本检查与有限帧启动。调整旧测试只能因获批规则变化，不得删断言掩盖问题。
