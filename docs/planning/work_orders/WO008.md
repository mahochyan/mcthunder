## 2. 实现步骤

1. 仅对已穿过外装甲的弹丸，按车内路径顺序处理模块进入事件；同次直穿单一模块最多结算一次，非命中模块不受直击伤害。

2. 为发动机、左右履带、炮闩、炮塔驱动、弹药架和四名乘员维护独立运行状态；配置耐久与穿透消耗是游戏数值。履带作为外部模块可被直接命中。

3. 集中计算 VehicleCapabilities：可驱动/可转向/可开火/炮塔速度/装填倍率。车辆驱动和武器读取同一结果，HUD 只显示它。

4. 发动机损毁失去主动动力，车辆按减速规则停止，炮塔仍可使用；任一履带损毁首版停止主动移动；炮闩损毁不能射击；炮塔驱动损毁限制转速或禁止，选定规则写入 GAME_RULES。

5. 乘员失能不可普通维修复活；炮手/驾驶员无人时对应功能暂不可用；装填手失能导致装填变慢。少于2名可用乘员触发失去战斗能力。

6. 弹药架受损本单先记录状态，不提前伪造殉爆效果；009 接入真实终结规则。所有事件带 shot_id 便于后续回放。
