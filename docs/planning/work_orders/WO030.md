## 2. 实现步骤

1. 主菜单包含继续教学/开始游戏、车库、挑战、靶场、设置、制作与许可信息、退出；去掉不可用的假按钮和“敬请期待”占位主流程。

2. 自由对战配置为选车、配弹、地图、难度→加载→准备→比赛→结算→再来一局/返回车库；加载失败给具体原因和返回入口。

3. 结算显示胜负、票数、命中/击穿/击毁、占点贡献、关键死亡原因；统计来自同一事件记录，反复进入结算不重复累加。

4. 全流程统一管理场景切换、鼠标捕获、暂停、音频与运行实例，避免每个按钮自行操作全局树。

5. 在加载/存档动作期间避免重复点击多次开局；退出比赛有确认，退出整个游戏不损坏已提交成绩。

6. 主菜单显示游戏版本和规则版本，便于用户反馈；开发调试入口默认隐藏但不删除测试能力。

## 3. 自动检查与集成验收

下面是要实际实现和运行的验收案例，不是已有测试通过记录。每个测试调用真实生产逻辑，记录源码SHA、命令、种子和结果。

**T030-02**：连续快速点击开始、重开、返回时最多创建一场比赛，无重叠音乐或多个鼠标控制器。

**T030-03**：暂停退出、阵亡退出、结算再开和切地图各重复10次，无旧对象持续更新。

**T030-04**：同局结算统计与事件摘要一致，重复查看不重复计成绩。
