## 2. 实现步骤

1. 以约400×400米灰盒图为基础：中央据点、两条主进攻路线、一条较长侧翼路线，出生区用地形或实体遮挡隔开。尺寸是设计起点，可按驾驶速度调整。

2. 典型交火距离80—250米；设置可利用坡顶、低墙与村舍，不让所有交战都变成长走廊正面对射。

3. 给每种地物明确视觉与碰撞：建筑和石墙挡弹，首版薄围栏也可挡弹但外观必须清楚；草不挡弹，灌木感知规则统一给玩家与AI。

4. 完成路点图、出生点集合、维修/补给区域的预留；补给在022统一接入，不在地图脚本私自赠送弹药。

5. 检查四种未来车型所需的最大宽度与炮塔空间，狭窄区域提供绕行，避免地图只适配初始中型车。

## 3. 自动检查与集成验收

下面是要实际实现和运行的验收案例，不是已有测试通过记录。每个测试调用真实生产逻辑，记录源码SHA、命令、种子和结果。

**T018-01**：两侧出生点之间没有直接主炮射界，据点到各方主路线的初始行驶时间差记录清楚。

**T018-02**：每侧至少两条独立到据点的可行路径，任一路被车堵住仍有替代路线。

**T018-03**：固定路径探测覆盖每个出生点到据点；最大车宽测试模型能通过声明可通行道路。

**T018-04**：地图外边界与视觉一致，无看似可走却无形阻挡的主要路线。
