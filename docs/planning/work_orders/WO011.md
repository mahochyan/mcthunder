## 2. 实现步骤

1. 将003—010集成进一个有明确测试区的靶场：驾驶区、厚度板区、斜甲区、可恢复的样车区。旧基础靶板可以保留，功能不能混淆。

2. 提供选定样车重置、装甲/内构显示、发射参数查看和无限训练弹开关；全部只在训练环境生效。

3. 设计五个固定实验：正面防护、侧后弱点、发动机失能、炮闩失能、空弹药架；射击位置与初始状态固定，便于用户复现。

4. 加入最小可读反馈：命中/未穿/跳弹不同音效或提示、炮口和受击效果、模块状态；此阶段可以用原创合成占位资源，026再提升品质。

5. 输出“一炮解释卡”：为什么穿/未穿、实际打到哪、车辆为何还能打或为何出局。把不一致列为阻塞问题。

6. 运行全部回归，并做一轮完整 GUI 试玩。未拿到用户认可前只标记 v0.1 候选，不开始增加正式车型。
