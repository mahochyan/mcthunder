## 2. 实现步骤

1. 建立 ShotQueryService，统一处理物理世界遮挡、车辆装甲有限面片和内部有向盒交点。首版可扫描最多 8 辆车的小规模数据，先保证正确，不先做复杂空间树。

2. 世界实体查询在安全物理更新阶段进行；车辆粗碰撞体只用于驾驶/粗筛，不能抢先吞掉装甲面命中。碰撞层掩码和排除集合集中配置。

3. 将世界线段转换到各部件局部坐标检测，再把交点/法线转换回世界；记录 distance_m、vehicle_id、part_id、surface_id 或 module_id、进出点。

4. 把墙体、装甲和模块候选合并排序。模块只有经后续穿甲授权才能受伤；本服务只提供几何交点，不自行判伤。

5. 处理端点、恰在表面出发、从模块内部出发、相邻装甲接缝、共面交点和浮点容差；真实多层装甲保留，重叠建模错误不能被偷偷当作额外装甲。

6. 保留炮根到炮口遮挡检查；设每段迭代上限和去重规则。禁止用“命中过此坦克就整车永久排除”来规避重复碰撞。

## 3. 自动检查与集成验收

下面是要实际实现和运行的验收案例，不是已有测试通过记录。每个测试调用真实生产逻辑，记录源码SHA、命令、种子和结果。

**T005-01**：同一线段依次经过前板、空舱、发动机、后板时，交点顺序与手算几何一致。

**T005-02**：墙在车前时，第一有效世界碰撞一定是墙；模块候选不触发伤害。

**T005-03**：旋转炮塔和车体后仍命中正确面 ID，不能只使用未变换 AABB。

**T005-04**：射线平行于面、起点位于盒内、击中接缝时不出现 NaN、无限循环或重复扣算。

**T005-05**：自身过滤只影响发射车；另一辆相同车型不能一并被过滤。

还必须重跑此前相关回归、资源导入/脚本检查与有限帧启动。调整旧测试只能因获批规则变化，不得删断言掩盖问题。
