## 2. 实现步骤

1. 为测试中型车定义车体/炮塔局部坐标、装甲面 ID、厚度、有限面片边界和外法线；车顶、底部、侧后面均要有定义。倾斜由真实面片方向表示，不用角度标签伪装。

2. 定义内部模块有向包围盒：发动机、左/右履带、炮闩、炮塔驱动、两处弹药架，以及车长/炮手/装填手/驾驶员。所有数值为游戏设计值，不标成历史数据。

3. 模块指定所属部件；炮塔旋转时炮闩、炮塔装甲和炮塔内乘员同步变化，车体模块不随炮塔转动。

4. 提供开发模式开关：线框装甲、厚度标签、模块盒、模块名称、局部坐标与选中高亮。正式战斗不得默认显示敌人 X 光。

5. 建立检查：唯一 ID、正厚度、尺寸非零、引用存在、明显越界、未声明的模块重叠；有意重叠必须白名单并说明。

6. 制作简单装甲样板与标准摆位；至少有 20/40/80 mm 测试板，0/30/60 度摆位和可旋转炮塔样车，供后续测试复用。
