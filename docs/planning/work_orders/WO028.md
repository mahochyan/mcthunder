## 2. 实现步骤

1. 在既有靶场实现可重玩的分步教学：开车到点→转炮/炮镜→命中薄靶→换角度攻击→击毁指定模块→维修/灭火→进入占点。

2. 教学步骤订阅实际移动、射击、伤害和占领事件；不能玩家随便点“下一步”就伪装学会。允许跳过并在菜单重进。

3. 每步只显示当前必要动作，按实际改绑显示键位；长时间未进展时给具体提示，不羞辱或自动替玩家完成。

4. 用真实结果解释“没打穿”“发动机坏了但炮还能打”“成员不足出局”；训练无限弹、重置和X光只在训练上下文生效。

5. 教学检查点只保存到章节级，重进时恢复该步骤的预设场景；首版不保存任意时刻的炮弹/物理状态。
