## 2. 实现步骤

1. 建立明确状态迁移：正常/受损/起火/失能/已摧毁；首版不将所有状态塞进互斥单枚举，允许引擎损毁与起火并存，但终结状态只能触发一次。

2. 按 GAME_RULES 的阈值或带种子规则处理发动机起火；火灾定期影响声明的关联模块，不能跨车辆随意伤人。保存起火来源用于击毁归属。

3. 弹药架必须绑定实际剩余弹数。空架不殉爆；非空且达到殉爆条件时直接终结本车，产生唯一死亡事件。装填/换弹/补给不得复制弹药。

4. F 灭火：2次可配置耗材，默认4秒动作；T 维修：驻车且未起火才推进，履带/炮闩/发动机按模块顺序维修至可用阈值，不能同时无限修复所有部件。

5. 默认维修基础时长12秒，灭火和维修的中断/重开是否保留进度写清；普通维修不能恢复失能乘员、已殉爆车辆或消耗的弹药。

6. 实现8秒乘员换位：有可用替补且不让同一人占两个岗位；默认优先炮手再驾驶员，装填手缺位仍保留惩罚。取消或重伤必须清理进行中的换位。

7. 残骸失去控制但保留合理遮挡；设残骸生命周期和数量预算，生成/清理不得重复计分。首版殉爆不伤害邻车，以免提前引入爆炸范围系统。
