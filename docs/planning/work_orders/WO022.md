## 2. 实现步骤

1. 车库列出4款已解锁车辆，展示机动、防护、火力的真实配置摘要；不以未经实测的综合战力分数制造假精确。

2. 提供原创车辆旋转预览、装甲厚度模式和内构模式；预览使用无战斗行为的显示对象，避免车库也运行AI/装填/伤害。

3. 可选择AP/APHE备弹分配，总数不超过车型容量；训练可自由设置，正式战斗默认满备弹，也允许少带降低弹药架风险。

4. 将选车、弹种分配、地图和难度组成 MatchConfig，启动比赛时创建独立快照；预览调参不能实时改变正在运行的车辆。

5. 补给仅在自方指定补给区驻车满足条件后缓慢进行，按容量增加指定弹种并更新弹药架；敌方不能使用，自方火灾时不可补给。

6. 首版全部车辆直接可用，不加入银币维修费、氪金或长期科技树；挑战星级/战绩提供轻量目标。
