## 2. 实现步骤

1. 从真实炮口生成 ProjectileState，包含 shot_id、发射者、队伍、弹种、位置、速度、累计路程、生命期和随机种子；开火时扣弹和进入装填，只执行一次。

2. 使用固定物理步推进重力，逐步检测上一位置到新位置的整条线段；禁止只检查炮弹当前小球是否重叠。视觉弹道不能决定伤害。

3. 使用 005 查询服务；本单碰到第一处装甲或墙先停止并反馈，穿透留给 007。保留炮根—炮口遮挡，不能发射到墙后。

4. 配置首轮测试速度 300 m/s、重力 9.81 m/s²，寿命和距离上限集中设置。这是游戏调试弹，不是历史弹性能。

5. 暂停时不推进弹道和装填，重置/离开场景时回收炮弹；设置活动炮弹数量上限，达到上限不得造成无声命中或死循环。

6. 将生产弹道积分函数用于测试；轨迹线、示踪与后坐订阅事件。有限速度下瞄点先表示炮管直线方向，不伪称它能精确预测落点。
