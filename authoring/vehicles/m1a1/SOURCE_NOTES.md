# M1A1 HC：按原精模与概念图制作的三档低模

当前有效交付在 `production_lods/`。这是可审阅的模型资产版本；未接入游戏，未进行多人场景性能验收。

用户提供的高精模负责部件位置、比例和轮廓；概念图负责沙漠色与 USMC / A22 标识。按用户最新要求省略后部行李、外挂备用轮、绑带、工具、天线及高大的外挂附件。旧 `output/`、`concept_v2/` 和旧 `m1a1_lod/` 已被否决，不应作为本轮成果。

| 三角形预算 | 实际三角形 | 贴图尺寸 | 导出网格 / 材质 | 建议用途（待游戏实测） |
|---|---:|---:|---|---|
| 4K | 3896 | 2048×2048 | 3 / 1 | 玩家车辆、近景 |
| 2K | 1922 | 2048×2048 | 3 / 1 | 常规车辆、中景 |
| 1K | 966 | 1024×1024 | 3 / 1 | 远景 |

这里 4K / 2K / 1K 是三角形预算，不是贴图分辨率。没有为凑满预算增加无用面。

建模来源：
- 车体、炮塔、裙板等用源部件的凸包轮廓约束局部简化；这种方法会简化凹口，并非逐面忠实重拓扑。
- 炮管直接求交原高模的轴向截面，保留抽烟器、粗细阶跃和凹入炮口。
- 两侧各七个负重轮及前后轮按源部件位置、尺寸拟合径向网格；履带外轮廓来自原材质 22/23 的顶点。
- 舱盖按源部件可见高度与尺寸重建；细小附件按三档预算取舍。
- `template_lods/*/SOURCE_MAP.json` 记录逐部件源索引和方法。`source_components.json` 对应 `source_welded.blend` 的面索引。

贴图：
- 已给新拓扑展开 AtlasUV。
- `normal.png`：Cycles 高模→低模切线空间法线，OpenGL +Y。对应部件分开烘焙后还原位置，避免邻近部件串投。
- `ao.png`：低模自身 AO。
- `base_color.png`：根据用户概念图重建的沙漠漆、橡胶色和标识，烘焙到新 UV。原模型未附原始彩色贴图，因此这不是原游戏贴图的恢复。
- `orm.png`：R=AO，G=粗糙度，B=金属度。GLB 内嵌颜色、法线与 ORM；Blender 文件也打包所需图片。

每档导出 Body / Turret / Gun 三个网格，共用一张材质；TurretPivot、GunPivot 为根据源部件拟合的初始功能轴，尚需在游戏内验证运动与遮挡。GLB 坐标 Y 向上、-Z 车头，单位米。轮组目前并入 Body，不含车轮旋转或履带滚动动画。

验证已完成：实际 GLB 重新导入、三档预算、三个网格和单材质、UV 在 0–1 内、坐标有限、无退化三角形、焊合 UV 接缝后网格闭合、炮塔/炮管轴节点存在。模型约 9.785 米长、3.659 米宽；这是原资产尺度，不是史料尺寸认证。

四个同角度投影中，与本轮保留的高模结构部件相比，轮廓 IoU 范围：4K 94.50–99.91%，2K 94.32–99.59%，1K 92.91–99.29%。这只量化外轮廓重合，不能代替局部造型、美术质量和性能验收。详细数据在 `production_lods/VALIDATION.json`。

查看 `production_lods/comparison.png` 的贴图实模、`geometry_comparison.png` 的同相机灰模，以及每档 front / side / rear / top 四视图。低模彩图均由重新导入的最终 GLB 渲染。

脚本：`template_lods.py` 生成源约束几何，`bake_production.py` 展 UV、烘焙与导出，`verify_production.py` 重新导入验证并渲染。命令使用 `E:\blender\blender.exe --background --python-exit-code 1 --python <脚本>`。最终烘焙与导出复查进程均退出 0，日志分别为 `bake_production_final.log`、`verify_production.log`。

用户要求生图辅助，但当前会话没有可调用的生图工具；本轮直接使用用户提供的概念图，没有声称调用生图，也没有把概念图当模型渲染。原始素材未覆盖，资产未推送到远端。
