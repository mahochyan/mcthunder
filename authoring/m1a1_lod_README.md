# M1A1 HC 低模 LOD 分析

输入精模约 204,333 面、218k 顶点；损伤网格约 75,389 面；X-ray 网格约 55,424 面。它们适合作为烘焙源，不直接作为实时网格。

| 档位 | 贴图 | 建议可见三角形 | 用途 |
|---|---:|---:|---|
| LOD0 | 4096² | 100k–140k | 车库、回放特写 |
| LOD1 | 2048² | 45k–70k | 战斗近中距离 |
| LOD2 | 1024² | 15k–30k | 中远距离、多车 |
| LOD3 | 512² | 5k–12k | 远景 |

Blender Decimate 副本实测：LOD0 126,686 三角形，LOD1 61,299，LOD2 24,518。原目录未被修改，输出位于用户目录的 `lod_output`，未纳入游戏资源库。
